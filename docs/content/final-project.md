# Финалдық жоба: өз AI Reels-іңізді нөлден жасаңыз

Бұл — курстың басты нәтижесі. Сіз идеядан бастап жарияланған вертикал видеоға дейінгі бүкіл жолды **тек смартфонмен** өз бетіңізше өтесіз.

> 📱 **Не керек:** смартфон, ChatGPT, GitHub аккаунты, Claude қосымшасы (Pro немесе одан жоғары жазылым). Шамамен уақыт: **2–3 сағат** (оның 30–60 минуты — Claude жұмыс істеген кезде күту).

## 🎯 Тапсырма

Өз тақырыбыңызға **15–30 секундтық** вертикал видео (1080×1920) жасаңыз:

- қазақ тіліндегі кинетикалық мәтін немесе субтитрлер;
- авторлық құқықсыз музыка және дыбыс эффектілері;
- кемінде 4 сахна, анимациялар мен өтпелер;
- күшті ілгек (алғашқы 2 секунд) және соңында CTA.

## 🪜 10 қадам

Әр қадамды орындағанда белгі қойыңыз — прогресіңіз осы құрылғыда сақталады.

### 1-кезең: Дайындық (ChatGPT)

- [ ] **1. Идея.** «Видео идеясын нақтылау» промптымен 5 идея алып, біреуін таңдадым. ([1-модуль, 4-сабақ](#/lesson/m01-l04))
- [ ] **2. Сценарий.** «Сценарий генераторы» арқылы 4–6 сахналы кесте-сценарий жаздым, ілгек пен CTA бар. ([2-модуль, 4-сабақ](#/lesson/m02-l04))
- [ ] **3. Негізгі промпт.** Негізгі промпттың барлық [ЖАҚШАЛАРЫН] толтырдым, «Заметки»-ге сақтадым. ([2-модуль, 5-сабақ](#/lesson/m02-l05))

### 2-кезең: Жоба орны (GitHub)

- [ ] **4. Репозиторий.** README-мен private репозиторий құрдым, оған `brief.md` қостым. ([3-модуль](#/modules/m03))
- [ ] **5. Claude-ты қосу.** GitHub-ты Claude-қа қостым, Claude GitHub App-ты осы репоға орнаттым, сынақ сессиясы файлдарды көрді. ([4-модуль, 3–4-сабақ](#/lesson/m04-l03))

### 3-кезең: Видео жасау (Claude Code)

- [ ] **6. Генерация.** Негізгі промптты Claude Code-қа жібердім, Claude есебін және branch атауын алдым. ([4-модуль, 5-сабақ](#/lesson/m04-l05))
- [ ] **7. Тексеру.** Видеоны GitHub-тан телефонға жүктеп, бағалау чек-листімен тексердім. ([4-модуль, 6-сабақ](#/lesson/m04-l06))
- [ ] **8. Жақсарту.** Кемінде 2 жақсарту жасаттым (анимация, типография, субтитр, дыбыс немесе эффектілер) және финалдық экспорт пен мұқабаны алдым. ([5-модуль](#/modules/m05))

### 4-кезең: Жариялау

- [ ] **9. Сипаттама.** 3 сипаттама нұсқасы мен 5 хэштег дайындадым. ([6-модуль, 4-сабақ](#/lesson/m06-l04))
- [ ] **10. Жариялау.** Видеоны кемінде бір платформаға жарияладым (немесе «Тек мен» режимінде жүктедім) және 7 видеоға контент-жоспар жасадым. ([6-модуль](#/modules/m06))

## ✅ Өзін-өзі бағалау: сапа критерийлері

Видеоңызды тексеріңіз. Әр «иә» — 1 ұпай. **8 және одан жоғары — кәсіби деңгей.**

- [ ] Формат 1080×1920, ұзақтығы 15–30 секунд
- [ ] Алғашқы 2 секундта назар аудартатын ілгек бар
- [ ] Барлық мәтін толық көрінеді, қазақ әріптері дұрыс
- [ ] Мәтін қауіпсіз аймақта (жоғарғы, төменгі және оң жақ шет бос)
- [ ] Әр 2–4 секунд сайын визуалды өзгеріс бар
- [ ] Анимациялар жұмсақ (easing), статикалық слайд-шоу емес
- [ ] Музыка мен дыбыс эффектілері бар, авторлық құқық бұзылмаған
- [ ] Емле мен грамматика дұрыс
- [ ] Соңында анық CTA бар
- [ ] Видеоны досыңызға көрсеттіңіз — ол басты ойды бір сөйлеммен қайталап бере алды

## 💬 Финалдық жобаға арналған промпттар

Барлық промпттар **Промпттар** бөлімінде. Финалдық жоба үшін ең маңыздылары:

1. **Сценарий генераторы** (ChatGPT) — 2-қадам.
2. **Негізгі промпт** (Claude Code) — 6-қадам.
3. **Түзетулер тізімі** және **Видеоның техникалық тексерісі** — 7–8-қадамдар.
4. **Финалдық экспорт** — 8-қадам.
5. **Сипаттама мен хэштегтер генераторы** — 9-қадам.
