# 02 · ChatGPT және промпт инженериясы — видеосабақ сценарийлері

> Барлық видеода жалпы техникалық талаптар сақталады (1-модуль сценарийлерінің басын қараңыз). Тіркелу сәтінде поштаны және кодты бұлдыратыңыз.

---

## 2.1 ChatGPT-пен жұмыс істеу (≈6 мин)

| Уақыт | Экранда | Дикторлық мәтін |
|---|---|---|
| 0:00–0:20 | ChatGPT белгісі | «Бүгін ChatGPT-ті телефоннан қолдануды үйренеміз.» |
| 0:20–1:20 | App Store → «ChatGPT» → әзірлеуші OpenAI | Ресми қосымшаны тану. Балама: chatgpt.com браузерде. |
| 1:20–2:50 | Тіркелу (пошта/Google/Apple) → растау коды | Әр батырманы атап көрсету. Кодты бұлдырату. |
| 2:50–4:00 | Чат интерфейсі: хабарлама жолы, жіберу, жаңа чат, мәзір | Әр элементке саусақпен нұсқау (монтажда шеңбермен белгілеу). |
| 4:00–5:20 | Сценарист промптын жіберу → жауапты көшіру → «Заметки»-ге қою | Көшіру белгісі және ұзақ басу тәсілі. |
| 5:20–6:00 | Дауыспен жазу (микрофон) | Ұзын сипаттамалар үшін кеңес. |
