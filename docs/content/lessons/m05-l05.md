# Өтпелер

## 🎯 Сабақ мақсаты

Сахналар арасындағы өтпелердің (transitions) түрлерін білу және оларды музыка ырғағымен үйлестіру.

## 📖 Түсіндірме

**Өтпе** — бір сахнадан келесіге ауысу тәсілі. Жақсы өтпе көрерменді «ұстап» қалады, ал нашар өтпе назарды бөледі.

| Өтпе | Сипаттама | Сезім |
|---|---|---|
| **Hard cut** (тікелей кесу) | Бірден келесі сахна | Энергия, жылдамдық (ең жиі қолданылады) |
| **Zoom-through** | Камера мәтінге «кіріп», келесі сахнаға өтеді | Динамика, вау-әсер |
| **Whip / slide** | Экран бір жаққа жылдам «сырғиды» | Қозғалыс, жалғасу |
| **Wipe** | Түсті жолақ/пішін экранды жауып ашады | Графикалық, таза |
| **Circle reveal** | Шеңбер үлкейіп, жаңа сахнаны ашады | Акцент, финал |
| **Glitch cut** | Қысқа бұзылу әсері | Шиеленіс, технология |
| **Match cut** | Пішін не түс келесі сахнада жалғасады | Ақылды, кәсіби |
| **Fade** | Біртіндеп күңгірттену | Баяу, эмоционалды (Reels-те сирек) |

### Ырғақ ережесі

Өтпелер музыканың **битіне** (соққысына) сәйкес келгенде видео «бір тыныста» көрінеді. Мысалы, 120 BPM музыкада бит әр **0.5 секунд** сайын соғады — сахналар 2.0, 2.5, 3.0 секундтарда ауысады.

> 💡 **Кәсіби құпия:** өтпе кезіндегі **дыбыс эффектісі** (whoosh — «зу-у», impact — соққы) өтпенің өзі сияқты маңызды. Дыбыссыз өтпе әлсіз сезіледі.

## 🪜 Қадамдар

1. Видеоңыздағы барлық сахна ауысуларын санаңыз.
2. Әр ауысуға өтпе түрін таңдаңыз. Көбі — hard cut, 2–3 жерде ерекше өтпе.
3. Ең маңызды ауысуға (мысалы, мәселеден шешімге) ең әсерлі өтпені қойыңыз.
4. Промптты толтырып, жіберіңіз.

## ✍️ Практикалық тапсырма

Видеоңыздағы өтпелерді музыка битіне сәйкестендіріп, кемінде 2 ерекше өтпе (zoom-through, wipe, circle reveal) қостырыңыз.

## 💬 Дайын промпт

```prompt
# Ырғақты өтпелер
Видеодағы сахна ауысуларын жақсарт:
1) Көп ауысу — музыка битіне дәл түсетін hard cut + жеңіл масштаб соққысы (1.06 → 1.0, 0.25 с).
2) [1→2 СӘТ, мысалы: ілгектен мәселеге] — zoom-through өтпе.
3) [МӘСЕЛЕДЕН ШЕШІМГЕ] — қысқа glitch немесе түсті wipe.
4) Финалдық CTA алдында — circle reveal.
5) Әр ерекше өтпеге сәйкес дыбыс эффектісі (whoosh, impact) қос.
Сахна шекараларын музыка битіне (BPM бойынша) тураласын. Қайта рендерле, тексер, push жаса.
```

## ✅ Күтілетін нәтиже

Видео ырғақты, сахналар бір-бірімен табиғи жалғасады, өтпелер дыбыспен күшейтілген.

## ⚠️ Жиі қателер және шешімдері

- **Әр ауысу әртүрлі өтпе.** Шешімі: 70–80% hard cut, қалғаны ерекше өтпелер.
- **Өтпе тым ұзақ (1+ секунд).** Шешімі: өтпелер 0.15–0.4 секунд болсын.
- **Өтпе ырғақтан тыс.** Шешімі: «сахна шекараларын музыка битіне тураласын» деп жазыңыз.
