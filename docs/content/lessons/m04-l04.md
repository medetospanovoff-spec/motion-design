# Жобаны іске қосу

## 🎯 Сабақ мақсаты

Claude Code-та репозиторийді таңдап, жаңа бұлттағы сессияны дұрыс баптаулармен ашу.

## 📖 Түсіндірме

Жаңа сессия ашқанда 3 нәрсені таңдайсыз:

1. **Репозиторий** — Claude қай жобада жұмыс істейді (`my-first-reels`).
2. **Орта (environment)** — бұлттағы компьютердің баптаулары (бізде **Default**). Ресми құжаттамаға сәйкес, бірінші хабарлама жіберілгеннен кейін сессияның ортасын өзгерту мүмкін емес.
3. **Рұқсат режимі (permission mode)** — Claude өзгерістерді сұрамай жасай ма:
   - **Accept edits** — Claude файлдарды өзгертіп, branch-ті сұрамай жібереді.
   - **Auto** — Claude өз бетінше көбірек әрекет етеді (қолжетімді болса).
   - **Plan** — алдымен жоспар жазып, сіздің мақұлдауыңызды күтеді.

> 💡 **Ұсыныс:** алғашқы видео үшін **Accept edits** немесе **Auto** режимін таңдаңыз — Claude тоқтамай жұмыс істейді. **Plan** таңдасаңыз, Claude жоспар ұсынғаннан кейін оны мақұлдауыңыз керек, әйтпесе ол күтіп тұра береді.

> ⚠️ Қосымшада бұл таңдаулардың орны мен атауы сәл басқаша болуы мүмкін. Ресми браузер нұсқасында репозиторий таңдау **хабарлама жолының астында** орналасқан.

## 🪜 Қадамдар

1. Claude қосымшасында **Code** бөлімін ашыңыз (немесе браузерде `claude.ai/code`).
2. Жаңа сессия бастаңыз (жаңа тапсырма / New session). Браузерден тікелей: `claude.ai/code/new`.
3. **Репозиторий таңдау** батырмасын басып, `my-first-reels` таңдаңыз.
4. Branch — әдепкі `main` қалсын.
5. **Орта** — **Default** таңдалғанын тексеріңіз.
6. **Рұқсат режимі** — **Accept edits** немесе **Auto**.
7. Әзірге хабарлама жібермеңіз! Алдымен сынақ сессиясын жасаймыз (төменде).

### Сынақ сессиясы (2 минут)

Үлкен промптты жібермес бұрын байланыстың жұмыс істейтінін тексерейік. Хабарлама жолына төмендегі **«Байланысты тексеру»** промптын қойып жіберіңіз. Claude репоңыздағы файлдарды санап береді. Бұл жұмыс істесе — бәрі дұрыс қосылған.

## ✍️ Практикалық тапсырма

Сынақ сессиясын жүргізіңіз. Claude `README.md` және `brief.md` файлдарын көргенін растасын.

## 💬 Дайын промпт

```prompt
# Байланысты тексеру
Сәлем! Бұл — сынақ. Қазақ тілінде жауап бер:
1) Осы репозиторийде қандай файлдар бар? Тізімін жаз.
2) brief.md файлында не жазылғанын 2 сөйлеммен айт.
3) Ортада python3, node және ffmpeg орнатылған ба? Тексеріп, нәтижесін жаз.
Ешқандай файлды өзгертпе.
```

## ✅ Күтілетін нәтиже

Claude репоңыздың файлдарын тізіп, `brief.md` мазмұнын айтып берді. Демек GitHub байланысы жұмыс істейді.

## ⚠️ Жиі қателер және шешімдері

- **«Repository not found» / репо таңдауда жоқ.** Шешімі: 3-сабаққа оралып, Claude GitHub App-ты репоға орнатыңыз.
- **Сессия басталмайды.** Шешімі: интернетті тексеріп, қосымшаны қайта ашыңыз. Жазылым лимиті біткен болуы мүмкін — біраз күтіңіз.
- **Claude жоспар жазып, тоқтап қалды.** Шешімі: Plan режимі таңдалған — жоспарды мақұлдаңыз немесе жаңа сессияны Accept edits режимінде ашыңыз.
