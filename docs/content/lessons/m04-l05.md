# Промптты жіберу

## 🎯 Сабақ мақсаты

Негізгі промптты Claude Code-қа дұрыс жіберу, жұмыс барысын бақылау және Claude-тың сұрақтарына жауап беру.

## 📖 Түсіндірме

Енді ең қызықты кезең! Сіз 2-модульде дайындаған **Негізгі промптты** жібересіз. Одан кейін Claude:

1. Жоспар жазады.
2. Ортаны тексеріп, қажетті құралдарды орнатады.
3. Код жазады (сахналар, анимация, музыка).
4. Видеоны рендерлейді (бірнеше минут).
5. Кадрларды тексеріп, қатені түзетеді.
6. Нәтижені GitHub-қа жібереді және есеп береді.

Бұл **10–40 минутқа** созылуы мүмкін. Барлық уақыт экранға қарап отырудың қажеті жоқ.

> 💡 **Ресми құжаттама бойынша:** сессия сіз қосымшадан шықсаңыз да ағымдағы тапсырманы аяқтағанша жұмысын жалғастырады. Біраз уақыттан кейін қайта кіріп, нәтижені қарайсыз.

## 🪜 Қадамдар

1. «Заметки»-ден толтырылған Негізгі промптты толығымен көшіріңіз (бәрін белгілеу → Копировать).
2. Claude қосымшасында **Code** → `my-first-reels` репосымен жаңа сессия ашыңыз (4-сабақтағыдай; сынақ сессиясын жалғастыруға да болады).
3. Хабарлама жолын ұзақ басып → **Вставить / Paste**.
4. Мәтіннің толық қойылғанын тексеріңіз: басы да, соңы («СОҢЫНДА маған...») да бар ма?
5. **Жіберу** батырмасын басыңыз.
6. Claude-тың алғашқы жауабын (жоспарын) оқыңыз.
7. Жұмыс барысында Claude әрекеттерін көрсетеді (файл құрды, команда орындады). Түсінбесеңіз — қорықпаңыз, бұл қалыпты.
8. Егер Claude **сұрақ қойса** — қысқа әрі нақты жауап беріңіз. Білмесеңіз: «Өзің ең жақсы нұсқаны таңда» деп жазыңыз.
9. Егер Claude **рұқсат сұраса** (Allow / Разрешить) — команданың сипаттамасын оқып, рұқсат беріңіз.
10. Claude соңғы есебін жазғанша күтіңіз: branch атауы және `output/video.mp4` туралы ақпарат.

## ✍️ Практикалық тапсырма

Негізгі промптты жіберіп, Claude-тың соңғы есебін алыңыз. Есептегі **branch атауын** «Заметки»-ге көшіріп алыңыз — оны келесі сабақта қолданамыз.

## 💬 Дайын промпт

Егер Claude жұмыс кезінде тоқтап қалса немесе не істеп жатқанын түсінбесеңіз:

```prompt
# Жұмыс барысын сұрау
Қазір не істеп жатырсың? Қазақ тілінде қысқа жауап бер:
1) Не дайын болды?
2) Не қалды?
3) Менен бір нәрсе керек пе?
Егер ештеңе керек болмаса — тоқтамай жұмысты соңына дейін жалғастыр.
```

```prompt
# Шешімді Claude-тың өзіне қалдыру
Мен бағдарламалауды білмеймін, сондықтан бұл техникалық сұрақты өзің шеш. Видеоның сапасы мен сенімділігі үшін ең жақсы нұсқаны таңда, қысқаша себебін жаз да, жұмысты жалғастыр.
```

## ✅ Күтілетін нәтиже

Claude жұмысын аяқтап, қазақ тілінде есеп берді: видео қай branch-те, `output/video.mp4` файлында, ұзақтығы мен көлемі қанша.

## ⚠️ Жиі қателер және шешімдері

- **Промпттың тек бір бөлігі қойылды.** Шешімі: «Заметки»-де мәтінді толық белгілеп (Выбрать всё) көшіріңіз. Жіберер алдында соңын тексеріңіз.
- **Claude ағылшынша жауап береді.** Шешімі: «Әрі қарай тек қазақ тілінде жауап бер» деп жазыңыз.
- **Сессия ұзақ уақыт бойы өзгермейді.** Шешімі: «Жұмыс барысын сұрау» промптын жіберіңіз. Телефонды жауып, 10–15 минуттан кейін қайта қараңыз.
- **Лимит бітті деген хабар.** Шешімі: жазылым лимиті қалпына келгенше күтіңіз, содан кейін сол сессияда «жалғастыр» деп жазыңыз.
- **Бір уақытта бірнеше сессия ашу.** Шешімі: бір видео — бір сессия. Әйтпесе лимит тез бітеді және файлдар шатасады.
