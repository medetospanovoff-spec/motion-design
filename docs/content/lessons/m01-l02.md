# AI арқылы видео жасау қалай жұмыс істейді?

## 🎯 Сабақ мақсаты

Видео монтаж бағдарламасынсыз, тек мәтін арқылы видео қалай пайда болатынын түсіну.

## 📖 Түсіндірме

Әдетте видео былай жасалады: адам CapCut, Premiere сияқты бағдарламада мәтінді, суретті, музыканы қолмен орналастырады. Бұл көп уақыт пен тәжірибені талап етеді.

Біздің әдісіміз басқаша:

1. Сіз **сөзбен** сипаттайсыз: қандай сахналар, қандай мәтін, қандай түстер, қандай музыка.
2. **Claude Code** бұл сипаттаманы **кодқа** айналдырады. Код дегеніміз — компьютерге арналған нұсқаулық тізімі (мысалы: «2-секундта экран ортасына үлкен ақ мәтін шықсын»).
3. Код іске қосылғанда, компьютер видеоның әр **кадрын** (бір секундта 30 сурет) салады.
4. Соңында кадрлар мен дыбыс біріктіріліп, **MP4** видео файл пайда болады.

> 💡 **Мультфильм сияқты:** мультфильм көп суреттен тұрады. Claude Code сол суреттерді қолмен емес, код арқылы салады. Сондықтан ол бір промпттан 900 кадрды бірнеше минутта жасай алады.

### Неге бұл жақсы?

- **Монтаж білу қажет емес** — сіз тек не қалайтыныңызды жазасыз.
- **Өзгерту оңай** — «мәтінді үлкейт» деп жазсаңыз, бүкіл видео қайта жасалады.
- **Қайталауға болады** — бір промпт үлгісінен ондаған видео шығару мүмкін.
- **Бәрі бұлтта** — ауыр жұмысты сіздің телефоныңыз емес, Claude Code-тың бұлттағы компьютері атқарады.

> 📱 **Телефон үшін маңызды:** видео сіздің телефоныңызда емес, интернеттегі (бұлттағы) компьютерде жасалады. Телефон тек «пульт» ретінде қолданылады. Сондықтан ескі телефон да жарайды.

### Бұл әдістің шектеулері

- Нақты адамдарды түсіретін «кино» жасамайды — біз **моушн-дизайн** (анимацияланған мәтін, графика, эффектілер) жасаймыз.
- Нәтиже промптқа тәуелді: бұлыңғыр сипаттама → бұлыңғыр видео.
- Кейде бірінші нұсқада қате болады — оны түзету жолын 4-модульде үйренеміз.

## 🪜 Қадамдар

1. Басты беттегі мысал-видеоны қараңыз (курс басындағы видео).
2. Оны қарап отырып, қағазға немесе «Заметки»-ге жазыңыз: қанша сахна бар? Қандай түстер? Мәтін қалай пайда болады?
3. Енді ойлаңыз: осының бәрін **сөзбен** сипаттауға бола ма? Иә — дәл осы сипаттама промптқа айналады.

## ✍️ Практикалық тапсырма

Өзіңіз ұнататын кез келген Reels немесе TikTok видеосын ашыңыз. Оның алғашқы 5 секундын сөзбен сипаттап жазыңыз: «Қара фон. Ортада үлкен сары мәтін «...». Мәтін төменнен ұшып шығады...». Бұл — промпт жазуға алғашқы жаттығу.

## 💬 Дайын промпт

```prompt
# Видеоны сөзбен сипаттауға үйрену
Мен видеоларды сөзбен сипаттауды үйреніп жатырмын. Төмендегі сипаттамамды оқып, оны моушн-дизайнер түсінетіндей нақтырақ етіп қайта жаз: әр сахнаның уақыты (секунд), фон түсі, мәтін, мәтіннің пайда болу анимациясы.
Менің сипаттамам: [ВИДЕО ТУРАЛЫ ӨЗ СӨЗІҢІЗБЕН ЖАЗЫҢЫЗ]
Жауапты қазақ тілінде, кесте түрінде бер.
```

## ✅ Күтілетін нәтиже

Видео «мәтін → код → кадрлар → MP4» жолымен жасалатынын түсіндіңіз және видеоны сөзбен сипаттап көрдіңіз.

## ⚠️ Жиі қателер және шешімдері

- **«AI кез келген фильмді жасайды» деп күту.** Шешімі: бұл курста мәтін, графика, анимация негізіндегі видеолар жасаймыз — олар Reels-те өте жақсы жұмыс істейді.
- **Сипаттаманы тым жалпы жазу** («әдемі болсын»). Шешімі: түсті, өлшемді, уақытты атаңыз: «қызғылт сары фон, 2 секунд».
