# Файлдарды жүктеу

## 🎯 Сабақ мақсаты

Телефоннан репозиторийде жаңа мәтіндік файл құру және телефондағы файлдарды (сурет, дыбыс, логотип) репозиторийге жүктеу.

## 📖 Түсіндірме

Репоға файл қосудың екі жолы бар:

1. **Create new file** — жаңа мәтіндік файлды тікелей браузерде жазу (мысалы, `brief.md`).
2. **Upload files** — телефондағы дайын файлды жүктеу (сурет, логотип, дауыс жазбасы).

Әр өзгерістен кейін GitHub **Commit changes** (өзгерісті сақтау) сұрайды. Commit хабарламасы — не өзгергенінің қысқа сипаттамасы, мысалы: «brief.md қосылды».

> ⚠️ **Шектеу:** браузер арқылы бір файлдың көлемі **25 MB**-тан аспауы керек. Ұзын видеоларды жүктемеңіз — бізге керек емес.

### Видео үшін қандай файлдар пайдалы

- `brief.md` — видео туралы тапсырма (тақырып, сценарий).
- `logo.png` — брендіңіздің логотипі (бар болса).
- `voice.m4a` — өз дауысыңыздың жазбасы (5-модульде).
- Өз суреттеріңіз — авторлығы сізге тиесілі болса ғана.

## 🪜 Қадамдар

### А. Жаңа файл құру (brief.md)

1. Репозиторийіңізді ашыңыз: `github.com/USERNAME/my-first-reels`.
2. **Add file** (немесе **+**) → **Create new file** басыңыз. Батырма көрінбесе, тікелей сілтемені ашыңыз: `github.com/USERNAME/my-first-reels/new/main`.
3. Жоғарғы өріске файл атауын жазыңыз: `brief.md`.
4. Төменгі үлкен өріске мәтінді жазыңыз немесе қойыңыз. Мысал:

```
# Менің видеом
Тақырып: Үйде кофе қайнату
Көрермен: студенттер
Ұзақтығы: 20 секунд
Стиль: қоңыр фон, ақ мәтін
```

5. **Commit changes...** басыңыз.
6. Шыққан терезеде commit хабарламасы: «brief.md қосылды». **Commit directly to the main branch** таңдалғанын тексеріңіз.
7. **Commit changes** басыңыз. Файл репода пайда болады.

### Б. Телефоннан файл жүктеу

1. Репода **Add file** → **Upload files** басыңыз. Немесе сілтеме: `github.com/USERNAME/my-first-reels/upload/main`.
2. **choose your files** сілтемесін басыңыз.
3. Телефон файл таңдауды ашады:
   - **iPhone:** «Фото медиатека» (суреттер үшін) немесе «Выбрать файлы» (Файлдар қосымшасы).
   - **Android:** «Файлы» / «Галерея» / «Документы».
4. Файлды таңдаңыз. Жүктелу аяқталғанша күтіңіз.
5. Төменде commit хабарламасын жазыңыз: «логотип қосылды».
6. **Commit changes** басыңыз.

> 📱 **Файл атауы туралы:** iPhone суреттерді кейде `IMG_1234.HEIC` атымен жүктейді. HEIC форматын кейбір бағдарламалар оқымайды. Сурет жіберер алдында оны скриншот жасап (PNG) немесе «Файлдар» қосымшасына JPG ретінде сақтап, сосын жүктеген дұрыс. Немесе Claude-қа «HEIC файлды PNG-ге айналдыр» деп жазуға болады.

## ✍️ Практикалық тапсырма

1. `brief.md` файлын құрып, ішіне видеоңыздың тақырыбы мен 2-модульдегі сценарийді қойыңыз.
2. (Міндетті емес) Логотипіңізді немесе бір суретті жүктеңіз.

## ✅ Күтілетін нәтиже

Репозиторийде `README.md` және `brief.md` файлдары бар. Файл құру мен жүктеуді білесіз.

## ⚠️ Жиі қателер және шешімдері

- **Файл атауында кеңейтім жоқ** (`brief` деп жазылған). Шешімі: файлды ашып, қалам белгісін (Edit) басыңыз, атауын `brief.md` етіп өзгертіп, commit жасаңыз.
- **«File is too big».** Шешімі: 25 MB-тан кіші файл жүктеңіз немесе файлды қысыңыз.
- **Upload батырмасы мобильді нұсқада жоқ.** Шешімі: `/upload/main` сілтемесін ашыңыз немесе Desktop site режимін қосыңыз.
- **Commit жасалмай қалды** (бетті жауып тастадыңыз). Шешімі: файл сақталмаған — қадамдарды қайталаңыз, соңында **Commit changes** басуды ұмытпаңыз.
