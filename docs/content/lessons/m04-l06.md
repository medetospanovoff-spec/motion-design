# AI арқылы видео құрылымын жасау

## 🎯 Сабақ мақсаты

Claude жасаған жобаны түсіну, видеоны тауып, телефонға жүктеп алу және алғашқы түзетулерді сол сессияда сұрау.

## 📖 Түсіндірме

Claude жұмысын бітіргенде сізде:

- **Branch** — мысалы, `claude/...` деген атпен.
- **Changes** (өзгерістер) — Claude қосқан файлдар. Ресми браузер нұсқасында чаттың жанында **Changes** картасы және `+42 -18` сияқты сандар көрінеді; оларды басып, өзгерістерді (diff) қарауға болады.
- **Create PR** батырмасы — өзгерістерді `main`-ге қосуды ұсыну.
- **output/video.mp4** — сіздің видеоңыз.

> ⚠️ Ресми құжаттамада видео файлды Claude қосымшасынан тікелей жүктеп алу тәсілі сипатталмаған. Сондықтан сенімді жол — **GitHub арқылы** жүктеу (3-модуль, 7-сабақ).

### Видео құрылымы қалай көрінеді

Claude әдетте видеоны бөліктерге бөледі:

- **Конфиг / сценарий файлы** (мысалы `script.json`) — мәтіндер мен уақыттар.
- **Сахналар** — әр сахна жеке функция немесе блок.
- **Дыбыс** — генерацияланған музыка және эффектілер.
- **Рендер скрипті** (мысалы `generate.py`) — бәрін біріктіріп MP4 жасайды.

Бұл құрылым болашақта өте пайдалы: келесі видео үшін тек мәтіндерді ауыстырасыз да, Claude-тан «жаңа сценариймен қайта жаса» деп сұрайсыз.

## 🪜 Қадамдар

### 1. Видеоны табу және жүктеу

1. Браузерде репоңызды ашыңыз: `github.com/USERNAME/my-first-reels`.
2. Branch таңдау батырмасынан (`main`) Claude-тың branch-ін таңдаңыз (атауын Claude есебінен алдыңыз).
3. `output` → `video.mp4` ашыңыз.
4. Жүктеу / View raw басып, видеоны телефонға сақтаңыз (iPhone: Бөлісу → «Сохранить видео»; Android: ⋮ → «Скачать»).
5. Галереядан немесе «Файлдар»-дан ашып, **дыбысы қосулы** толық қараңыз.

### 2. Видеоны бағалау

Қарап отырып, мына сұрақтарға жауап жазыңыз:

- [ ] Барлық мәтін толық көрінеді ме (кесілмеген)?
- [ ] Қазақ әріптері (Ә, Қ, Ң, Ө, Ұ, Ү, І) дұрыс па?
- [ ] Мәтінді оқып үлгересіз бе?
- [ ] Алғашқы 2 секунд көз тарта ма?
- [ ] Музыка бар ма, тым қатты емес пе?
- [ ] Соңғы кадрда CTA анық па?

### 3. Түзетуді сұрау

1. Claude Code-тағы **сол сессияға** оралыңыз (Code бөліміндегі сессиялар тізімінен).
2. Төмендегі «Түзетулер тізімі» промптын өз ескертпелеріңізбен толтырып жіберіңіз.
3. Claude видеоны қайта жасап, push жасайды. Видеоны қайта жүктеп, тексеріңіз.

## ✍️ Практикалық тапсырма

Алғашқы видеоңызды телефонға жүктеп, бағалау чек-листін толтырыңыз. Кемінде бір түзету сұрап, жаңа нұсқаны жүктеңіз. **4-модульдің практикасын белгілеңіз!**

## 💬 Дайын промпт

```prompt
# Түзетулер тізімі
Видеоны қарадым. Мына түзетулерді енгіз, видеоны қайта рендерле, тексер және push жаса:
1) [МЫСАЛЫ: 2-сахнадағы мәтін тым ұсақ — 1.5 есе үлкейт]
2) [МЫСАЛЫ: 4-сахнадағы мәтін тез жоғалады — 1 секундқа ұзарт]
3) [МЫСАЛЫ: музыка тым қатты — 30% бәсеңдет]
Басқа ештеңені өзгертпе. Соңында не өзгергенін қазақ тілінде қысқа жаз.
```

```prompt
# Жоба құрылымын түсіндіру
Осы жобаның құрылымын маған бағдарламалауды білмейтін адамға түсіндіргендей қазақ тілінде түсіндір: қай файл не үшін керек, видеодағы мәтінді өзгерту үшін қай файлды өзгерту керек, видеоны қалай қайта жасауға болады. Ешқандай файлды өзгертпе.
```

## ✅ Күтілетін нәтиже

**Алғашқы AI-видеоңыз телефоныңызда!** Сіз оны бағалап, кемінде бір түзету жасаттыңыз. **4-модульдің негізгі нәтижесі орындалды.**

## ⚠️ Жиі қателер және шешімдері

- **Branch тізімінде Claude-тың branch-і жоқ.** Шешімі: Claude push жасамаған болуы мүмкін. Сессияда: «Барлық өзгерісті commit жасап, push жаса, branch атауын жаз» деп сұраңыз.
- **Видео жүктелмейді / тым үлкен.** Шешімі: «Видеоны 30 MB-тан аз етіп қайта кодта (H.264, yuv420p)» деп сұраңыз.
- **Түзету сұрағанда Claude бәрін қайта жасап жіберді.** Шешімі: промптқа «Басқа ештеңені өзгертпе» деп қосыңыз.
