# GitHub-пен жұмыс істеу

## 🎯 Сабақ мақсаты

Claude Code-қа GitHub аккаунтыңызды қосу және private репозиторийіңізге рұқсат беру.

## 📖 Түсіндірме

Claude Code-тың сіздің репоңызда жұмыс істеуі үшін екі нәрсе керек:

1. **GitHub-ты Claude аккаунтына қосу** (авторизация) — Claude сіздің атыңыздан GitHub-пен сөйлесе алады.
2. **Claude GitHub App** орнату — бұл private репозиторийлерге рұқсат. Ресми құжаттама бойынша, сессия кез келген **public** репоны клондай алады, бірақ **private** репода тек Claude GitHub App орнатылған болса жұмыс істейді.

> 💡 **Қауіпсіздік:** GitHub App орнатқанда **Only select repositories** (тек таңдалған репозиторийлер) опциясын таңдаңыз. Сонда Claude тек сіз рұқсат берген репоны көреді.

## 🪜 Қадамдар

### 1. GitHub-ты қосу

1. Телефон браузерінде `claude.ai/code` ашыңыз (Claude аккаунтыңызбен кіріңіз). Немесе Claude қосымшасының **Code** бөлімін ашыңыз — қосу ұсынысы сол жерде де шығуы мүмкін.
2. **Connect GitHub** (GitHub қосу) ұсынысын басыңыз.
3. GitHub авторизация беті ашылады. GitHub-қа кірмеген болсаңыз — кіріңіз.
4. **Authorize** (рұқсат беру) басыңыз.
5. GitHub сізді `claude.ai/code` бетіне қайтарады.

### 2. Claude GitHub App орнату

1. Онбординг кезінде **Install GitHub App** ұсынысы шықса — басыңыз. Шықпаса, браузерде ашыңыз: `github.com/apps/claude/installations/new`.
2. Аккаунтыңызды (username) таңдаңыз.
3. **Only select repositories** таңдаңыз → тізімнен `my-first-reels` таңдаңыз.
4. **Install** (немесе **Install & Authorize**) басыңыз.
5. GitHub құпиясөзді немесе 2FA кодын сұрауы мүмкін — енгізіңіз.

### 3. Ортаны (environment) тексеру

Pro және Max жоспарларында онбординг кезінде **Default** атты орта өздігінен құрылады. Оның интернет деңгейі — **Trusted**. Әзірге ештеңе өзгертудің қажеті жоқ.

### 4. Кейін басқа репоға рұқсат беру

GitHub-та: профиль суреті → **Settings** → **Applications** → **Installed GitHub Apps** → **Claude** → **Configure** → **Repository access** бөлімінде жаңа репоны қосыңыз → **Save**.

> 📱 Бұл беттер телефонда ыңғайсыз көрінсе, браузерде **Desktop site** режимін қосыңыз (3-модуль, 4-сабақ).

## ✍️ Практикалық тапсырма

GitHub-ты Claude-қа қосыңыз және Claude GitHub App-ты тек `my-first-reels` репосына орнатыңыз.

## ✅ Күтілетін нәтиже

Claude Code-та жаңа сессия ашқанда репозиторий таңдау тізімінде `my-first-reels` көрінеді.

## ⚠️ Жиі қателер және шешімдері

- **Репо тізімде жоқ.** Шешімі: Claude GitHub App осы репоға орнатылғанын тексеріңіз (Installed GitHub Apps → Claude → Configure). Репоны қосып, сақтаңыз.
- **Authorize-дан кейін ештеңе болмады.** Шешімі: `claude.ai/code` бетін жаңартыңыз немесе қосымшаны қайта ашыңыз.
- **«All repositories» таңдап қойдым.** Шешімі: қателік емес, бірақ қауіпсіздік үшін Configure арқылы «Only select repositories» етіп өзгертіңіз.
- **Team/Enterprise аккаунтында GitHub қосылмайды.** Шешімі: құжаттамаға сәйкес ұйым әкімшісі (Owner) GitHub коннекторын қосуы керек — әкімшіге хабарласыңыз.
