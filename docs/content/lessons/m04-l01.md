# Claude Code дегеніміз не?

## 🎯 Сабақ мақсаты

Claude Code-тың не екенін, оның ChatGPT-ден айырмашылығын және видеоны қалай жасайтынын түсіну.

## 📖 Түсіндірме

**Claude** — Anthropic компаниясының AI-көмекшісі. **Claude Code** — Claude-тың бағдарламашы режимі. Ол:

- Код **жазады** (сөйлесіп қана қоймайды).
- Кодты бұлттағы компьютерде **іске қосады**.
- Нәтижені **өзі тексереді** және қатені түзетеді.
- Барлық файлды сіздің **GitHub репозиторийіңізге** сақтайды.

| | ChatGPT (чат) | Claude Code |
|---|---|---|
| Не береді | Мәтін-жауап | Жұмыс істейтін жоба + файлдар |
| Кодты іске қоса ма | Чатта — шектеулі | Иә, бұлттағы толық компьютерде |
| GitHub-пен жұмыс | Жоқ | Иә: жобаны алады, нәтижені push жасайды |
| Бізде рөлі | Сценарист | Аниматор-монтаждаушы |

### Бұлттағы сессия (cloud session) деген не?

Сіз Claude қосымшасының **Code** бөлімінде тапсырма бересіз → Anthropic бұлтында уақытша компьютер іске қосылады → ол сіздің репоңызды көшіріп алады → Claude жұмыс істейді → нәтижені GitHub-тағы жеке branch-ке жібереді.

> 💡 **Телефонды жауып қоюға болады.** Ресми құжаттамаға сәйкес, сессия сіз қосымшадан шықсаңыз да, ағымдағы тапсырманы бітіргенше жұмысын жалғастырады. Кейін қайта кіріп, нәтижені көресіз.

### Шектеулер (шынайы)

- **Ақылы жазылым қажет:** Pro, Max, Team немесе Enterprise.
- Бұлттағы сессиялар жазылымыңыздың **жалпы лимитінен** жұмсалады. Видео рендерлеу — «ауыр» жұмыс. Лимит бітсе, біраз уақыт күту керек болуы мүмкін.
- Бұлттағы компьютердің интернетке шығуы **шектеулі** (әдепкі деңгей — **Trusted**: пакет репозиторийлері, GitHub және кейбір сенімді домендер). Кейбір сайттардан жүктеу жұмыс істемеуі мүмкін — сондықтан Негізгі промптта «балама жол тап» деп жаздық.
- Claude да қателеседі — нәтижені тексеру сіздің міндетіңіз.

## 🪜 Қадамдар

1. Курстың басты бетіндегі мысал-видеоны тағы бір қараңыз — ол дәл осы әдіспен, Claude Code арқылы бір толық промпттан жасалған.
2. «Заметки»-ге жазыңыз: Claude Code қандай 4 әрекет жасайды (жазады, іске қосады, тексереді, сақтайды).
3. Жазылым бағасын және сіздің еліңізде қолжетімділігін `claude.com/pricing` бетінен тексеріңіз.

## ✍️ Практикалық тапсырма

Негізгі промптыңызды (2-модуль) қайта оқып, Claude Code түсінбеуі мүмкін жерлерді белгілеңіз. Мысалы, «әдемі» сияқты нақты емес сөздерді нақты сипаттамамен ауыстырыңыз.

## ✅ Күтілетін нәтиже

Claude Code не істейтінін, қандай шектеулері барын және оның ChatGPT-ден айырмашылығын білесіз.

## ⚠️ Жиі қателер және шешімдері

- **Claude Code-ты кәдімгі Claude чатымен шатастыру.** Шешімі: видео жасау үшін қосымшадағы **Code** бөлімін қолданамыз — ол GitHub-пен жұмыс істейді.
- **Нәтижені тексермей жариялау.** Шешімі: әрқашан видеоны толық қарап шығыңыз.
