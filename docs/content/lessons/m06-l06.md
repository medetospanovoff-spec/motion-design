# Контент идеяларын генерациялау

## 🎯 Сабақ мақсаты

ChatGPT көмегімен бір айға жететін видео идеяларын жасау және бір промпт үлгісінен көп видео шығару жүйесін құру.

## 📖 Түсіндірме

Бір видео — бастама. Нәтиже **жүйелі** жариялаудан келеді. Енді сізде құрал бар: Claude Code-та видео жобаңыз дайын, оны жаңа сценариймен қайта қолдануға болады.

### Контент рубрикалары

Рубрика — қайталанатын видео түрі. Бір рет құрылымын жасасаңыз, кейін тек мәтінін ауыстырасыз.

| Рубрика | Мысал | Құрылымы |
|---|---|---|
| **«3 қате»** | «Кофе қайнатудағы 3 қате» | Ілгек → 3 пункт → CTA |
| **«Бұрын / Кейін»** | «Бұрын 3 сағат, қазір 5 минут» | Контраст → шешім |
| **«Миф пен шындық»** | «AI бәрін өзі істейді ме?» | Миф → шындық → дәлел |
| **«1 кеңес»** | «Бүгінгі бір кеңес» | Бір нақты кеңес |
| **«Сан»** | «90% адам білмейді...» | Сан → түсіндіру |
| **«Сұрақ-жауап»** | Пікірдегі сұраққа жауап | Сұрақ → жауап |

### Бір жобадан көп видео

Claude Code-та **сол репозиторийде** жаңа сессия ашып:

> «Осы жобаның стилін сақтап, жаңа сценариймен жаңа видео жаса: output/video2.mp4»

деп жазсаңыз, Claude бар кодты қайта қолданады — жұмыс жылдамырақ әрі стиль бірыңғай болады.

## 🪜 Қадамдар

1. ChatGPT-ге «Контент-жоспар» промптын жіберіңіз.
2. Ұнаған 7 идеяны таңдаңыз.
3. Әр идеяға «Сценарий генераторы» промптымен (2-модуль) сценарий жасаңыз.
4. Claude Code-та «Жаңа видео сол стильде» промптымен видеоларды бірінен соң бірі жасаңыз.

## ✍️ Практикалық тапсырма

7 видеодан тұратын контент-жоспар жасаңыз (рубрика, тақырып, ілгек). **6-модульдің практикасын белгілеңіз!** Енді **Финалдық жобаға** өтіңіз.

## 💬 Дайын промпт

```prompt
# Контент-жоспар (30 идея)
Сен — контент-стратегсің. Менің блогым туралы:
- Тақырып / сала: [САЛА]
- Көрермен: [КІМГЕ]
- Мақсат: [ЖАЗЫЛУШЫ / САТУ / БЕДЕЛ]
Қазақ тілінде 30 қысқа вертикал видео идеясын кесте түрінде жаса:
№ | рубрика (3 қате / бұрын-кейін / миф пен шындық / 1 кеңес / сан / сұрақ-жауап) | тақырып | алғашқы 2 секундтағы ілгек | CTA.
Идеялар қайталанбасын, жаңадан бастаушыға түсінікті болсын. Соңында ең күшті 7 идеяны белгіле.
```

```prompt
# Жаңа видео сол стильде (Claude Code үшін)
Осы репозиторийдегі видео жобасының стилін, түстерін, шрифттерін және кодын қайта қолданып, жаңа видео жаса.
Жаңа сценарий: [ЖАҢА СЦЕНАРИЙ КЕСТЕСІ]
Жаңа видеоны output/[АТАУЫ].mp4 етіп сақта, ескі видеоны өшірме. Сапасын тексер (мәтін кесілмеген, қазақ әріптері дұрыс), push жаса және branch атауын жаз.
```

## ✅ Күтілетін нәтиже

Сізде 7 видеоға контент-жоспар бар және бір жобадан көп видео шығаруды білесіз. **Барлық 6 модуль аяқталды!**

## ⚠️ Жиі қателер және шешімдері

- **Әр видеоны нөлден бастау.** Шешімі: бар жобаны қайта қолданыңыз — жылдам әрі бірыңғай.
- **Тым көп рубрика.** Шешімі: 2–3 рубрикаға тоқталыңыз.
- **Идеялар көп, жариялау жоқ.** Шешімі: күнтізбеге белгілеңіз: мысалы, аптасына 3 видео.
