# Визуалды эффектілер

## 🎯 Сабақ мақсаты

Видеоны «премиум» ететін эффектілерді білу және оларды шамадан тыс қолданбауды үйрену.

## 📖 Түсіндірме

Эффектілер — дәмдеуіш сияқты: дұрыс мөлшерде — дәмді, артық болса — бұзады.

| Эффект | Не істейді | Қашан қолдану |
|---|---|---|
| **Glow (жарқырау)** | Мәтін/объект айналасында жарық | Неон, түнгі стиль, акцент сөз |
| **Grain (түйіршік)** | Жеңіл «кинопленка» шуы | Бүкіл видеоға өте әлсіз (3–8%) — «қымбат» көрініс береді |
| **Vignette** | Шеттерін сәл қараңғылау | Назарды ортаға бағыттау |
| **Chromatic aberration** | Түстердің қызыл/көк бөлінуі | Глитч, шиеленіс сәті (қысқа) |
| **Glitch** | Кадрдың «бұзылуы» | Өтпелерде, 0.1–0.3 секунд |
| **Particles (бөлшектер)** | Ұшқындар, шаң, жұлдыздар | Шешім/жеңіс сәті |
| **Light rays (сәулелер)** | Ортадан тарайтын сәулелер | Басты хабарландыру |
| **Shake (сілкініс)** | Камера дірілі | Соққы сәті, 0.2–0.3 с |
| **Motion blur** | Жылдам қозғалыстың бұлдырлығы | Жылдам кіру/өтпе |

> 💡 **Ереже «бір сахна — бір басты эффект»:** әр сахнада тек бір басты эффект болсын. Ал grain мен vignette бүкіл видеоға фон ретінде әлсіз қойылады.

> ⚠️ **Жыпылықтау қаупі:** өте жылдам жарық жыпылықтауы (секундына 3 реттен көп) кейбір адамдарға зиянды болуы мүмкін. Қатты жарқылдарды қайталамаңыз.

## 🪜 Қадамдар

1. Видеоңыздың **ең маңызды сәтін** табыңыз (мысалы, шешім немесе CTA).
2. Оған бір «соққы» эффектісін таңдаңыз: particles, rays немесе glow.
3. Бүкіл видеоға әлсіз grain + vignette қосуды жоспарлаңыз.
4. Промптты толтырып, жіберіңіз.

## ✍️ Практикалық тапсырма

Видеоңызға бүкіл видеоға арналған әлсіз grain + vignette және бір басты сәтке арналған «соққы» эффектісін қостырыңыз.

## 💬 Дайын промпт

```prompt
# Премиум визуалды эффектілер
Видеоға талғаммен эффектілер қос:
1) Бүкіл видеоға: әлсіз film grain (мөлдірлігі 5–8%) және жұмсақ vignette.
2) [НЕГІЗГІ СӘТ, мысалы: 4-сахнадағы басты сөз] үшін: ортадан тарайтын жарық сәулелері + ұшқын бөлшектері + жеңіл камера сілкінісі (0.25 с).
3) Акцент сөздерге жұмсақ glow.
4) Сахна ауысқан бір жерде 0.15 секундтық glitch өтпесі.
Бір сахнада бір ғана басты эффект болсын. Секундына 3 реттен жиі жыпылықтайтын жарқыл болмасын. Мәтін оқылуы бұзылмасын. Қайта рендерле, тексер, push жаса.
```

## ✅ Күтілетін нәтиже

Видео «қымбат» көрінеді, бірақ мәтін анық оқылады және көз шаршамайды.

## ⚠️ Жиі қателер және шешімдері

- **Эффект мәтінді оқытпайды.** Шешімі: «эффект мәтіннің артында болсын, мәтін контрасты сақталсын» деп жазыңыз.
- **Видео «арзан» көрінеді** (бәрі жарқырайды). Шешімі: эффектілердің жартысын алып тастатыңыз.
- **Рендер тым ұзақ.** Шешімі: бөлшектер санын азайтуды сұраңыз.
