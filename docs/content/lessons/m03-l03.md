# Repository дегеніміз не?

## 🎯 Сабақ мақсаты

Репозиторийдің ішінде не болатынын, public мен private айырмашылығын және README файлының маңызын түсіну.

## 📖 Түсіндірме

**Репозиторий** — бір жобаның папкасы. Бір видео жоба = бір репозиторий (немесе бір репозиторийде бірнеше видео — қалауыңызша).

Репозиторийде:

- **Файлдар мен папкалар** (код, шрифттер, видео).
- **README.md** — жобаның «мұқабасы»: репозиторийді ашқанда төменде көрінетін сипаттама.
- **Тарих (commits)** — кім, қашан, не өзгертті.
- **Branches** — жобаның параллель нұсқалары.

### Public немесе Private?

| | **Public (ашық)** | **Private (жабық)** |
|---|---|---|
| Кім көреді | Интернеттегі барлық адам | Тек сіз (және сіз шақырғандар) |
| Claude Code | Ашық репоны клондай алады | **Claude GitHub App** орнатылуы керек (4-модульде көрсетеміз) |
| Ұсыныс | Портфолио үшін | Жеке жобалар, бастапқы жаттығу |

> 💡 **Біздің ұсынысымыз:** алғашқы жобаны **Private** етіп ашыңыз. Claude Code-қа рұқсат беруді 4-модульде қадамдап көрсетеміз. Кейін қаласаңыз, репоны Public етуге болады (Settings → Danger Zone → Change visibility).

### Файл атауы және кеңейтімі

Файл атауының соңындағы нүктеден кейінгі бөлік — **кеңейтім** (файл түрі):

- `.md` — Markdown мәтін (README.md)
- `.mp4` — видео
- `.py` — Python коды
- `.json` — баптаулар/деректер
- `.ttf` — шрифт

## 🪜 Қадамдар

1. Браузерде кез келген ашық репозиторийді ашыңыз, мысалы: `github.com/github/gitignore`.
2. Жоғарыдағы файлдар тізімін қараңыз. Кейбірі папка (белгісі — папка), кейбірі файл.
3. Төмен айналдырып, README мәтінін табыңыз.
4. Файлдар тізімінің үстінде **commits** санын табыңыз (сағат белгісі) — бұл жобаның тарихы.

## ✍️ Практикалық тапсырма

Өз репозиторийіңіздің атын ойлап табыңыз (латынша, бос орынсыз, сызықшамен): мысалы `my-first-reels`. «Заметки»-ге жазыңыз.

## ✅ Күтілетін нәтиже

Репозиторийдің не екенін, ішінде не болатынын және оны private ету керек пе, жоқ па, білесіз.

## ⚠️ Жиі қателер және шешімдері

- **Репо атауында бос орын немесе қазақ әріптері.** Шешімі: `my-first-reels` сияқты латынша, сызықшамен жазыңыз. GitHub бос орынды сызықшаға ауыстырады.
- **Құпия ақпаратты (құпиясөз, телефон нөмірі) public репоға салу.** Шешімі: ешқашан мұндай деректерді репоға салмаңыз.
