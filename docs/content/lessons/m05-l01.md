# Анимация жасау

## 🎯 Сабақ мақсаты

Анимацияның негізгі қағидаларын түсіну және Claude Code-қа «жанды» қозғалысты нақты сөзбен сипаттауды үйрену.

## 📖 Түсіндірме

**Анимация** — уақыт өте келе өзгеру: орны, өлшемі, түсі, мөлдірлігі. Кәсіби анимацияны әуесқойдікінен үш нәрсе ажыратады:

### 1. Easing (жеңіл бастау / тоқтау)

Шынайы өмірде заттар бірден жылдамдық алмайды және бірден тоқтамайды. Бірқалыпты (linear) қозғалыс «роботтық» көрінеді.

| Атауы | Сезім | Қашан қолдану |
|---|---|---|
| **ease-out** | Жылдам кіріп, жұмсақ тоқтайды | Мәтін кіргенде (ең жиі) |
| **ease-in** | Баяу басталып, үдейді | Объект кеткенде |
| **ease-in-out** | Жұмсақ басталып, жұмсақ бітеді | Камера қозғалысы |
| **back / overshoot** | Сәл асып кетіп, оралады | Батырмалар, иконкалар, «серпінді» мәтін |
| **bounce / elastic** | Секіреді | Ойнақы стиль (абайлап) |

### 2. Stagger (кезекпен шығу)

Бәрі бір мезгілде шықпайды: әріптер немесе сөздер **0.03–0.08 секунд** аралықпен кезекпен шығады. Бұл көзге ұнамды ырғақ береді.

### 3. Тайминг

- Кіру анимациясы: **0.2–0.5 секунд**.
- Мәтін экранда тұруы: оқуға жететіндей (шамамен **3 сөзге 1 секунд**).
- Шығу: кірудің жартысындай жылдам.

> 💡 **Қарапайым ереже:** «Жылдам кір, оқуға уақыт бер, жылдам шық».

### Сөздік: Claude-қа арналған анимация тілі

`slide in from bottom` (төменнен кіру), `scale from 0 to 1` (нөлден үлкею), `fade in` (біртіндеп пайда болу), `rotate` (айналу), `shake` (сілкіну), `pop` (серпіліп шығу), `parallax` (қабаттардың әртүрлі жылдамдықпен қозғалуы), `loop` (қайталану).

## 🪜 Қадамдар

1. Видеоңызды қарап, анимациясы ең әлсіз сахнаны табыңыз.
2. Оның қазіргі қозғалысын бір сөйлеммен сипаттаңыз.
3. Жоғарыдағы сөздікті қолданып, жаңа қозғалысты жазыңыз: «Сөздер төменнен кезекпен (0.05 с) кірсін, ease-out, 0.35 с».
4. Төмендегі промпт арқылы Claude-қа жіберіңіз.

## ✍️ Практикалық тапсырма

Видеоңыздағы кемінде 2 сахнаның анимациясын easing + stagger арқылы жақсартыңыз.

## 💬 Дайын промпт

```prompt
# Анимацияны кәсіби ету
Видеодағы барлық анимацияны кәсіби деңгейге көтер:
1) Linear қозғалыстарды easing-ке ауыстыр: кіру — ease-out (expo немесе cubic), шығу — ease-in.
2) Мәтін сөздері немесе әріптері кезекпен (stagger 0.03–0.06 с) шықсын.
3) Негізгі сөздер «pop» әсерімен (scale 0.6 → 1.05 → 1, back easing) шықсын.
4) Әр сахнада жеңіл камера қозғалысы болсын (баяу zoom 1.0 → 1.05).
5) Мәтін оқуға жеткілікті уақыт тұрсын (3 сөзге кемінде 1 секунд).
Тайминг сценарийден аспасын. Қайта рендерле, кадрларды тексер, push жаса.
```

## ✅ Күтілетін нәтиже

Видеодағы қозғалыстар жұмсақ, ырғақты және «қымбат» көрінеді.

## ⚠️ Жиі қателер және шешімдері

- **Анимация тым көп — көз шаршайды.** Шешімі: әр сахнада бір басты қозғалыс болсын.
- **Мәтін оқылмай жатып кетіп қалады.** Шешімі: «әр мәтін кемінде 1.5 секунд толық көрінсін» деп жазыңыз.
- **Bounce барлық жерде.** Шешімі: серпінді эффектілерді тек негізгі сөздерге қолданыңыз.

> ease-out табиғи көрінеді: заттар қозғалысты жұмсақ тоқтатады.
