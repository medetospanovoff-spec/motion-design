# Жобаның құрылымын түсіну

## 🎯 Сабақ мақсаты

Claude Code жасайтын видео жобасының файлдары мен папкаларын түсініп, қай файл не үшін керек екенін білу.

## 📖 Түсіндірме

Claude Code жұмысын бітіргенде репозиторийіңіз шамамен былай көрінеді (атаулар сәл өзгеше болуы мүмкін — оны Claude өзі таңдайды):

```
my-first-reels/
├── README.md          ← жоба сипаттамасы
├── brief.md           ← сіздің тапсырмаңыз
├── script.json        ← видеодағы мәтіндер мен уақыт (өзгертуге оңай)
├── generate.py        ← видеоны жасайтын негізгі скрипт
├── assets/
│   ├── fonts/         ← шрифттер (қазақ әріптерімен)
│   └── audio/         ← генерацияланған музыка
└── output/
    └── video.mp4      ← ДАЙЫН ВИДЕО
```

| Файл / папка | Не үшін | Сіз өзгертесіз бе? |
|---|---|---|
| `README.md` | Жоба туралы түсіндірме | Сирек |
| `brief.md` | Сіздің тапсырмаңыз | Иә |
| `script.json` / `config` | Мәтіндер, түстер, уақыт | Иә, кейде |
| `generate.py`, `.js` файлдар | Код | Жоқ — Claude өзгертеді |
| `assets/` | Шрифт, сурет, дыбыс | Сурет жүктесеңіз |
| `output/` | Нәтиже — видео | Жоқ, тек жүктеп аласыз |

> 💡 **Ең маңызды ереже:** код файлдарын өзіңіз өңдемеңіз. Бір нәрсе өзгерту керек болса — Claude Code-қа сөзбен жазыңыз: «Үшінші сахнадағы мәтінді ... деп өзгерт».

### Markdown (.md) — қарапайым белгілеу тілі

`README.md` пен `brief.md` **Markdown** тілінде жазылады. Ол өте қарапайым:

```
# Үлкен тақырып
## Кіші тақырып
- тізім элементі
**жуан мәтін**
```

GitHub бұл белгілерді әдемі мәтінге айналдырып көрсетеді.

## 🪜 Қадамдар

1. Өз репоңызды ашып, `brief.md` файлын басыңыз — GitHub оны пішімделген түрде көрсетеді.
2. Қалам белгісін (**Edit**) басыңыз — Markdown «шикі» түрде көрінеді.
3. Файлдың басына `# ` (тор + бос орын) қосып, тақырыпқа айналдырыңыз.
4. **Preview** қойындысын басып, нәтижені көріңіз.
5. **Commit changes** арқылы сақтаңыз.

## ✍️ Практикалық тапсырма

`brief.md` файлын Markdown арқылы реттеңіз: `# Тақырып`, `## Сценарий`, `## Стиль` бөлімдерін қосыңыз. Сақтаңыз.

## ✅ Күтілетін нәтиже

Видео жобасының қандай бөліктерден тұратынын білесіз және Markdown файлын өңдей аласыз.

## ⚠️ Жиі қателер және шешімдері

- **Код файлын қолмен өзгертіп, жобаны бұзып алу.** Шешімі: өзгерісті Claude Code-қа сөзбен тапсырыңыз. Бұзылып қалса, Claude-қа «соңғы өзгерісті қайтар» деп жазыңыз.
- **`#` белгісінен кейін бос орын жоқ.** Шешімі: `#Тақырып` емес, `# Тақырып` деп жазыңыз.
