# 03 · GitHub: мобильді жұмыс ортасы — видеосабақ сценарийлері

> **Маңызды:** бұл модульдің видеоларын **телефон браузерінде** (Safari және Chrome — екеуін де) түсіріңіз. Тест GitHub аккаунтын қолданыңыз. Пошта, 2FA кодтары, recovery codes міндетті түрде бұлдыратылсын. Батырма көрінбеген жағдайда «Desktop site» режимін видеода міндетті түрде көрсетіңіз.

| Уақыт | Экранда | Дикторлық мәтін |

| 0:30–2:30 | Email → Password → Username → Continue | Username ережелері. Құпиясөзді менеджерге сақтау. |
| 2:30–3:30 | Verify жұмбағы → Create account → 8 таңбалы код | Код келмесе — Спам. |
| 3:30–4:00 | Сауалнама → Skip / Free | Міндетті емес қадамдар. |
| 4:00–6:20 | Settings → Password and authentication → 2FA | «setup key» мәтінін көшіру (QR-ды сол телефонмен сканерлеу мүмкін емес). Recovery codes сақтау. |
| 6:20–7:00 | Профиль сілтемесі «Заметки»-ге | Қорытынды. |
