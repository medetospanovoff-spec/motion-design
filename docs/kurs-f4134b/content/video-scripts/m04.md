# 04 · Claude Code арқылы видео жасау — видеосабақ сценарийлері

> **Маңызды:** Claude қосымшасының **Code** бөлімін және браузердегі `claude.ai/code` бетін түсіріңіз. Видеоның басында қосымша нұсқасын және түсірілген күнін көрсетіңіз (интерфейс жиі жаңарады). Жазылым бағасын видеода айтпаңыз — `claude.com/pricing` бетіне сілтеме беріңіз. GitHub токендерін, поштаны бұлдыратыңыз. Claude-тың ұзақ жұмысын монтажда жылдамдатыңыз (×8–×16) және экранда «уақыт жылдамдатылған» деп жазыңыз.
