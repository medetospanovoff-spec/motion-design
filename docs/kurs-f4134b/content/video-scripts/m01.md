# 01 · AI әлеміне кіріспе — видеосабақ сценарийлері

**Жалпы техникалық талаптар (барлық модульге):**

- Телефонның **экран жазбасы**: iPhone — Басқару орталығы → «Запись экрана»; Android — жылдам баптаулар → «Запись экрана» (модельге байланысты).
- Вертикал 9:16, ұзақтығы **3–6 минут**. Дикторлық мәтінді алдын ала оқып, бөлек жазуға болады.
- Хабарландыруларды өшіріңіз («Не беспокоить»), экран жарықтығын максималды етіңіз.
- **Жеке деректерді** (пошта, пароль, телефон нөмірі, кодтар) монтажда бұлдыратыңыз немесе тест аккаунтты қолданыңыз.
- Интерфейс өзгеруі мүмкін — видеоның басында түсірілген күнін жазыңыз.
- Әр видео соңында: «Енді практикалық тапсырманы орындаңыз — ол сабақ бетінде».

## 1.1 Жасанды интеллект дегеніміз не? (≈4 мин)

| Уақыт | Экранда | Дикторлық мәтін (негізгі ойлар) |
|---|---|---|
| 0:00–0:15 | Курс логотипі, мысал-видеодан үзінді | «Бұл видеоны адам монтаждаған жоқ. Оны AI жасады. Бүгін AI деген не екенін түсінеміз.» |
| 0:15–1:10 | Қарапайым анимация/слайд: «AI = көмекші» | AI — үйренген бағдарлама; нұсқауды орындайды; промпт ұғымы. |
| 1:10–2:40 | Экран жазбасы: Safari → chatgpt.com → «10 жасар балаға түсіндір» сұрағы | Сұрақты жазу, жіберу, жауапты оқу. Екінші сұрақпен айырмашылықты көрсету. |
| 2:40–3:30 | Кесте: ChatGPT vs Claude Code | Кім не істейді: сценарист пен аниматор. |
| 3:30–4:00 | Сабақ беті, практикалық тапсырма | Тапсырманы түсіндіру, «Сабақты аяқтадым» батырмасын көрсету. |
