# Қарапайым промпт пен кәсіби промпт айырмашылығы

## 🎯 Сабақ мақсаты

Қарапайым промптты кәсіби промптқа айналдыруды үйрену және видео үшін нақты сипаттау тілін меңгеру.

## 📖 Түсіндірме

### Салыстыру

**Қарапайым промпт:**

> Кофе туралы әдемі видео жаса.

**Кәсіби промпт:**

> 20 секундтық вертикал видео (1080×1920). Тақырып: үйде кофе қайнату. Көрермен: 18–30 жастағы студенттер. Стиль: қою қоңыр фон, кремді-ақ ірі мәтін, жылы түстер. 5 сахна, әрқайсысы 3–4 секунд. 1-сахна (0–3 с): «КОФЕХАНАҒА АҚША ЖҰМСАМА!» — мәтін экранды толтырып, сілкініп шығады. Соңғы сахна: «Пікірге «КОФЕ» деп жаз». Субтитр экранның ортасында. Музыка: баяу емес, ырғақты.

Айырмашылық: кәсіби промптта **сандар, түстер, уақыт, мәтін және мақсат** бар. Claude Code-қа «әдемі» деген сөз ештеңе айтпайды, ал «қою қоңыр фон, 3 секунд» — нақты нұсқау.

### Видео сипаттаудың сөздігі

| Сөз | Мағынасы |
|---|---|
| **Сахна** | Видеоның бір бөлігі (әдетте 2–4 секунд) |
| **Ілгек (hook)** | Алғашқы 1–3 секунд — көрерменді ұстап қалу үшін |
| **Кинетикалық типография** | Қозғалатын, анимацияланған мәтін |
| **Өтпе (transition)** | Бір сахнадан келесіге ауысу тәсілі |
| **Акцент түс** | Маңызды сөздерді бөлетін ашық түс |
| **CTA** | Әрекетке шақыру: «жазыл», «пікір жаз» |
| **9:16** | Вертикал формат (телефон экраны) |

### Кәсіби промптты тексеру чек-листі

- [ ] Ұзақтығы көрсетілген (секунд)
- [ ] Формат: вертикал 1080×1920
- [ ] Көрермен кім екені айтылған
- [ ] Түстер мен стиль аталған
- [ ] Әр сахнаның уақыты мен мәтіні бар
- [ ] Ілгек пен CTA бар
- [ ] Тілі көрсетілген (қазақ тілі)

## 🪜 Қадамдар

1. «Заметки»-ге өз қарапайым промптыңызды жазыңыз (1 сөйлем).
2. Төмендегі «Промпт жақсартқыш» промптын ChatGPT-ге көшіріп, жақшадағы жерге өз сөйлеміңізді қойыңыз.
3. ChatGPT нұсқасын жоғарыдағы чек-листпен тексеріңіз.
4. Жетпей тұрған пунктті ChatGPT-ге «... қос» деп жазып, толықтырыңыз.

## ✍️ Практикалық тапсырма

Өз тақырыбыңызға қарапайым промптты кәсібиге айналдырыңыз. Чек-листтің 7 пунктінің бәрі орындалғанша жақсартыңыз. Нәтижені «Заметки»-ге сақтаңыз — оны келесі сабақта сценарийге айналдырамыз.

## 💬 Дайын промпт

```prompt
# Промпт жақсартқыш
Сен — промпт инженері және моушн-дизайнерсің. Менің қарапайым сипаттамамды Claude Code сияқты AI видео жасаушы түсінетін КӘСІБИ видео сипаттамасына айналдыр.
Менің сипаттамам: «[ҚАРАПАЙЫМ ПРОМПТ]»
Міндетті түрде қос: ұзақтығы (15–30 сек), формат 1080×1920 (9:16), көрермен, түстер (HEX кодымен), шрифт стилі, 4–6 сахна (әрқайсысының уақыты, экрандағы мәтіні, анимациясы), ілгек, CTA, музыка көңіл-күйі.
Экрандағы мәтін қазақ тілінде болсын. Жауапты бір блок мәтінмен бер, оны мен көшіріп алатындай.
```

## ✅ Күтілетін нәтиже

Сізде өз видеоңыздың кәсіби сипаттамасы бар және промпттың сапасын чек-лист арқылы тексере аласыз.

## ⚠️ Жиі қателер және шешімдері

- **«Әдемі», «керемет», «қызықты» сияқты бос сөздер.** Шешімі: түсін, өлшемін, жылдамдығын атаңыз.
- **Экранға тым көп мәтін.** Шешімі: бір сахнада 3–6 сөз. Ұзын ойды бірнеше сахнаға бөліңіз.
- **Түстерді атамау.** Шешімі: ChatGPT-ден «3 түстен тұратын палитра ұсын, HEX кодымен» деп сұраңыз.
