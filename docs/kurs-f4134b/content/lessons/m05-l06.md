# Дыбыс пен музыка

## 🎯 Сабақ мақсаты

Видеоға заңды музыка, дыбыс эффектілерін және (қаласаңыз) өз дауысыңызды қосу.

## 📖 Түсіндірме

Дыбыс — видео әсерінің жартысы. Үш қабат бар:

1. **Музыка (фон)** — көңіл-күй мен ырғақ.
2. **Дыбыс эффектілері (SFX)** — whoosh, pop, click, impact. Олар анимацияны «сезінуге» көмектеседі.
3. **Дауыс (voiceover)** — міндетті емес.

### Авторлық құқық — өте маңызды!

> ⚠️ **Танымал әндерді видео файлдың ішіне қоспаңыз.** Олар авторлық құқықпен қорғалған: видео бұғатталуы, дыбысы өшірілуі немесе аккаунтыңызға ескерту келуі мүмкін.

Заңды жолдар:

- **Claude генерациялаған музыка** — код арқылы синтезделеді (Негізгі промптта дәл осыны сұрадық). Ол сіздікі.
- **Платформаның музыка кітапханасы** — TikTok пен Instagram ішіндегі «Звук / Музыка» функциясы арқылы жариялау кезінде қосылады. Платформалардың лицензия шарттары әр аккаунт түріне (жеке / бизнес) қарай өзгеше болуы мүмкін — платформа ережелерін тексеріңіз.
- **Ашық лицензиялы музыка** — лицензиясы коммерциялық қолдануға рұқсат беретін болса ғана.

> 💡 **Ақылды тәсіл:** видеоның өз музыкасын бәсеңдетіп (немесе мүлдем алып тастап), жариялау кезінде платформадан тренд дыбысты қосуға болады. Бұл қамтуға (охват) көмектесуі мүмкін.

### Өз дауысыңызды жазу (телефонмен)

1. **iPhone:** «Диктофон» (Voice Memos) қосымшасы. **Android:** «Диктофон» / «Recorder» (телефонға байланысты).
2. Тыныш бөлмеде, телефонды аузыңыздан 15–20 см қашықтықта ұстаңыз. Жұмсақ заттар көп бөлме (кілем, перде) жақсы.
3. Сценарийді анық, энергиямен оқыңыз. Сөйлемдер арасында қысқа пауза жасаңыз.
4. Жазбаны файл ретінде сақтаңыз:
   - **iPhone:** жазбаны басып → «...» → **Бөлісу** → **«Сохранить в Файлы»**. Файл `.m4a` форматында болады.
   - **Android:** жазбаны бөлісу → «Файлдар»-ға сақтау.
5. Файлды `voice.m4a` деп атап, GitHub репоңызға жүктеңіз (3-модуль, 5-сабақ; көлемі 25 MB-тан аз болуы керек).

### Дыбыс деңгейлері

- Дауыс — ең қатты және анық.
- Музыка — дауыс кезінде **бәсеңдейді** (ducking).
- Жалпы қаттылық: әлеуметтік желілер үшін шамамен **−14 LUFS** (дыбыс қаттылығының стандарт өлшемі).

## 🪜 Қадамдар

1. Таңдаңыз: дауыссыз (тек музыка) немесе өз дауысыңызбен.
2. Дауыспен болса — жазып, `voice.m4a` етіп репоға жүктеңіз.
3. Сәйкес промптты Claude-қа жіберіңіз.
4. Видеоны **құлаққаппен** және **динамикпен** тыңдап тексеріңіз.

## ✍️ Практикалық тапсырма

Видеоңызға ырғақты музыка мен кемінде 3 түрлі дыбыс эффектісін қостырыңыз. Қаласаңыз, өз дауысыңызды қосыңыз.

## 💬 Дайын промпт

```prompt
# Музыка мен дыбыс эффектілері
Видеоның дыбысын кәсіби ет:
1) Фон музыкасын кодпен генерацияла (авторлық құқықсыз): [КӨҢІЛ-КҮЙ, мысалы: энергиялы электронды], темп [МЫСАЛЫ: 120] BPM, видео ұзақтығына дәл сай, соңы таза аяқталсын.
2) Дыбыс эффектілері: сахна ауысуында whoosh, мәтін шыққанда pop/click, басты сәтте impact. Олар анимациямен дәл синхронды болсын.
3) Жалпы қаттылықты шамамен −14 LUFS етіп қалыпқа келтір, клиппинг болмасын.
Дайын видеоны тексер (дыбыс жолы бар ма, ұзақтығы сай ма), push жаса.
```

2) Видео ұзақтығын дауысқа бейімде; сахналар дауыстағы сөйлемдермен сәйкес ауыссын.
3) Дауыс мәтіні: [ДАУЫС МӘТІНІН ОСЫНДА ЖАЗЫҢЫЗ]. Осы мәтіннен сөзбе-сөз шығатын субтитр жаса, дыбыстағы паузалар бойынша синхронда.
4) Дауыс кезінде музыканы бәсеңдет (ducking), дауыс анық естілсін.
Тексер, push жаса.

## ✅ Күтілетін нәтиже

Видеода заңды музыка, синхронды дыбыс эффектілері және (қаласаңыз) өз дауысыңыз бар.

## ⚠️ Жиі қателер және шешімдері

- **Музыка дауысты басып кетеді.** Шешімі: «дауыс кезінде музыканы 10 dB бәсеңдет» деп жазыңыз.
- **Дауыс жазбасында жаңғырық.** Шешімі: кішірек, жұмсақ заттар көп бөлмеде қайта жазыңыз.
- **Claude .m4a файлды оқи алмады.** Шешімі: «ffmpeg арқылы WAV-ке айналдыр» деп жазыңыз; ffmpeg жоқ болса, Негізгі промпттағы imageio-ffmpeg тәсілін еске салыңыз.
- **Танымал әнді видеоға қостыру.** Шешімі: мұны жасамаңыз — платформа кітапханасын қолданыңыз.
