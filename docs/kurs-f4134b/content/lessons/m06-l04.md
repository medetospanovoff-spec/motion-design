# Күшті тақырып пен сипаттама жазу

## 🎯 Сабақ мақсаты

Видеоға назар аудартатын тақырып, сипаттама (caption) және хэштегтер жазу.

## 📖 Түсіндірме

Видеоның айналасындағы мәтін үш міндет атқарады:

1. **Қызықтыру** — көрерменді видеоны қарауға итермелеу.
2. **Түсіндіру** — платформаға видео не туралы екенін айту (іздеу және ұсынымдар үшін).
3. **Әрекетке шақыру** — пікір, сақтау, жазылу.

### Сипаттама формуласы

```
1-жол: Ілгек (сұрақ, сан немесе батыл тұжырым)
2–3-жол: Пайда — көрермен не алады
4-жол: CTA (пікірге «...» деп жаз / сақтап қой)
Соңы: 3–5 хэштег
```

**Мысал:**

```
Монтажсыз видео жасау мүмкін бе? 🤯
Мен бұл видеоны бір промпт арқылы жасадым — бағдарламасыз, тек телефонмен.
Үйренгің келсе, пікірге «AI» деп жаз 👇
#AIвидео #қазақша #reels #моушндизайн
```

### Хэштегтер

- **3–5 хэштег** жеткілікті: 1–2 кең (`#reels`), 2–3 тақырыптық (`#AIвидео`, `#кофе`).
- Видеоға қатысы жоқ танымал хэштегтерді қоспаңыз — бұл спам.

### Іздеу сөздері

Адамдар TikTok пен Instagram-да **іздейді**. Видеоңыздың тақырыбын сипаттамада және экрандағы мәтінде қарапайым сөздермен атаңыз: «кофе қайнату», «AI видео жасау».

## 🪜 Қадамдар

1. Төмендегі промптты ChatGPT-ге жіберіңіз.
2. 3 нұсқаның ішінен ең ұнағанын таңдаңыз.
3. Өз сөзіңізбен түзетіп, «Заметки»-ге сақтаңыз.
4. Жариялағанда көшіріп қойыңыз.

## ✍️ Практикалық тапсырма

Видеоңызға 3 сипаттама нұсқасын және 5 хэштег жасатыңыз. Ең жақсысын таңдап сақтаңыз.

## 💬 Дайын промпт

```prompt
# Сипаттама мен хэштегтер генераторы
Сен — SMM маманысың. Менің вертикал видеом туралы мәлімет:
- Тақырып: [ТАҚЫРЫП]
- Басты ой: [БАСТЫ ОЙ]
- Көрермен: [КІМГЕ]
- Мақсат: [МЫСАЛЫ: пікірге «AI» деп жаздыру]
Қазақ тілінде жаса:
1) 3 сипаттама нұсқасы. Әрқайсысы: 1-жол — ілгек, 2–3-жол — пайда, соңында CTA. 300 таңбадан аспасын, 1–3 эмодзи.
2) 5 хэштег: 2 кең, 3 тақырыптық. Видеоға қатысы жоқ хэштег болмасын.
3) Видеоны іздеуде табу үшін 5 кілт сөз.
```

## ✅ Күтілетін нәтиже

Видеоңызға дайын сипаттама, хэштегтер және кілт сөздер бар.

## ⚠️ Жиі қателер және шешімдері

- **30 хэштег.** Шешімі: 3–5 нақты хэштег.
- **Кликбейт (видеода жоқ нәрсені уәде ету).** Шешімі: уәде видео мазмұнына сай болсын — әйтпесе көрермен кетеді және сенім жоғалады.
- **CTA жоқ.** Шешімі: әрқашан бір нақты әрекетке шақырыңыз.
