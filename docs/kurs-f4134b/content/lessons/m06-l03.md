# Видеоны жариялау

## 🎯 Сабақ мақсаты

Видеоны телефон галереясына сақтап, TikTok, Instagram Reels және YouTube Shorts-қа қадамдап жариялау.

## 📖 Түсіндірме

Жариялаудан бұрын видео **телефон галереясында** немесе **«Файлдар»** ішінде болуы керек (3-модуль, 7-сабақ). Қосымшалар видеоны сол жерден алады.

> 💡 **Сынап көру режимі:** алғашқы видеоны жеке режимде жариялап, қалай көрінетінін тексеруге болады (TikTok: «Тек мен / Только я»; Instagram: жабық аккаунт немесе «Жақын достар» мүмкіндіктері қосымша нұсқасына байланысты). Бәрі дұрыс болса — көпшілікке ашасыз.

> ⚠️ Қосымшалардың интерфейсі жиі өзгереді. Төмендегі қадамдар — жалпы бағыт. Батырмалардың аты мен орны басқаша болуы мүмкін.

## 🪜 Қадамдар

### 0. Видеоны галереяға сақтау (iPhone)

Егер видео «Файлдар» қосымшасында болса: файлды ашыңыз → **Бөлісу** → **«Сохранить видео»**. Енді ол «Фото» қосымшасында.

### 1. TikTok

1. TikTok қосымшасын ашып, төмендегі **«+»** батырмасын басыңыз.
2. **«Загрузить» / Upload** (галерея белгісі) басып, видеоңызды таңдаңыз.
3. **Далее / Next**. Қаласаңыз, TikTok кітапханасынан дыбыс қосыңыз (өз музыкаңыз болса, дыбыс деңгейін реттеңіз).
4. **Далее / Next** — жариялау беті:
   - Сипаттама (caption) және хэштегтер.
   - **Обложка / Cover** — мұқаба кадрын таңдаңыз.
   - **Кто может смотреть** — сынақ үшін «Только я», дайын болса «Все».
   - «Ещё / More options» ішінде **AI-generated content** белгісі болса — қосуды қарастырыңыз.
5. **Опубликовать / Post**.

### 2. Instagram Reels

1. Instagram ашып, **«+»** → **Reels** таңдаңыз.
2. Галереядан видеоңызды таңдаңыз → **Далее / Next**.
3. Редактор: қаласаңыз, музыка/мәтін қосасыз → **Далее / Next**.
4. Сипаттама, хэштегтер, **Обложка** (кадр таңдау немесе галереядан сурет — `cover.jpg`).
5. «Показывать в ленте» (лентада көрсету) опциясын тексеріңіз.
6. **Поделиться / Share**.

### 3. YouTube Shorts

1. YouTube қосымшасында **«+»** → **Создать Shorts / Create a Short** немесе **Загрузить видео**.
2. Вертикал видео қысқа болса, YouTube оны Shorts ретінде жариялайды (ұзақтық шегін YouTube анықтамасынан тексеріңіз).
3. Тақырып, сипаттама, көрерменді таңдау (балаларға арналған ба — міндетті сұрақ).
4. **Загрузить / Upload**.

## ✍️ Практикалық тапсырма

Видеоңызды кемінде бір платформаға жариялаңыз. Алғашқы рет — «Только я» режимінде, тексергеннен кейін көпшілікке ашыңыз.

## ✅ Күтілетін нәтиже

Видеоңыз платформада жарияланды (немесе жеке режимде жүктелді).

## ⚠️ Жиі қателер және шешімдері

- **Видео галереяда көрінбейді.** Шешімі: «Файлдар»-дан «Сохранить видео» арқылы галереяға сақтаңыз.
- **Сапасы нашарлап кетті.** Шешімі: Wi-Fi арқылы жүктеңіз; қосымша баптауларында «жоғары сапада жүктеу» опциясы болса, қосыңыз.
- **Платформа музыкасы видеоның өз музыкасымен араласып кетті.** Шешімі: біреуін таңдаңыз — не видеоның өз дыбысы, не платформа дыбысы (өзінікін бәсеңдетіңіз).
- **Instagram/TikTok видеоны кесіп тастады.** Шешімі: видео 9:16 (1080×1920) екенін тексеріңіз.
