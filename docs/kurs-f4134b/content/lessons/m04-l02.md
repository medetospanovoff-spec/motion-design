# Claude Code-ты мобильді құрылғыдан пайдалану

## 🎯 Сабақ мақсаты

Claude қосымшасын орнатып, тіркеліп, жазылымды рәсімдеп, **Code** бөлімін табу.

## 📖 Түсіндірме

Ресми құжаттамаға сәйкес Claude Code-тың жеке мобильді қосымшасы **жоқ**: бұлттағы сессиялар **Claude** қосымшасының (iOS және Android) **Code** қойындысында орналасқан. Сонымен қатар браузерде `claude.ai/code` мекенжайы бар.

> ⚠️ **Интерфейс туралы:** Claude қосымшасы жиі жаңарады. «Code» бөлімінің орны (төменгі мәзір немесе бүйір мәзір) сіздің нұсқаңызда басқаша болуы мүмкін. Табылмаса — қосымшаны жаңартыңыз.

### Сізге керек

- Claude аккаунты (`claude.ai`).
- **Pro** немесе одан жоғары жазылым (Max, Team, Enterprise).
- Claude қосымшасының соңғы нұсқасы.

## 🪜 Қадамдар

### 1. Қосымшаны орнату

1. **iPhone:** App Store → іздеу: «Claude». **Android:** Google Play → «Claude».
2. Әзірлеушісі **Anthropic** екенін тексеріңіз.
3. **Загрузить / Установить** басыңыз.

### 2. Тіркелу

1. Қосымшаны ашыңыз → электрондық пошта, Google немесе Apple арқылы кіріңіз.
2. Поштаға келген кодты немесе сілтемені растаңыз.
3. Сұралса, телефон нөмірін растаңыз.

### 3. Жазылымды рәсімдеу

1. Ең сенімді жол — браузерде `claude.ai` ашып, кіріп, баптаулардағы жазылым (Upgrade / Plans) бөлімінен **Pro** таңдау.
2. Кейбір елдерде жазылымды қосымшаның ішінде де (App Store / Google Play арқылы) рәсімдеуге болады. Баға мен шарттарды төлем алдында мұқият оқыңыз.
3. Төлем аяқталғаннан кейін қосымшаны жауып, қайта ашыңыз.

> ⚠️ Жазылым бағасы, салықтар және төлем әдістері елге қарай өзгереді. Ресми ақпарат: `claude.com/pricing`. Жазылымды кез келген уақытта тоқтатуға болады — шарттарын төлем бетінен оқыңыз.

### 4. Code бөлімін табу

1. Қосымшаның навигациясынан **Code** бөлімін басыңыз.
2. Бірінші рет кіргенде GitHub-ты қосу ұсынылуы мүмкін — оны келесі сабақта толық жасаймыз.
3. Балама: телефон браузерінде `claude.ai/code` ашыңыз (сол аккаунтпен).

## ✍️ Практикалық тапсырма

Claude қосымшасын орнатыңыз, кіріңіз және **Code** бөлімін табыңыз. Code бөлімінің скриншотын жасаңыз — кейін салыстыру үшін.

## ✅ Күтілетін нәтиже

Claude қосымшасы орнатылған, аккаунтқа кірдіңіз, жазылым белсенді және **Code** бөлімі ашылады.

## ⚠️ Жиі қателер және шешімдері

- **Code бөлімі жоқ.** Шешімі: (1) қосымшаны жаңартыңыз; (2) жазылым белсенді екенін тексеріңіз; (3) браузерде `claude.ai/code` ашып көріңіз.
- **Қосымшада және сайтта әртүрлі аккаунт.** Шешімі: бір поштамен кіріңіз — жазылым аккаунтқа байланған.
- **Төлем өтпейді.** Шешімі: картаның шетелдік төлемдерге ашық екенін тексеріңіз, басқа картаны немесе қосымша ішіндегі төлемді байқап көріңіз.
- **Claude еліңізде қолжетімсіз.** Шешімі: ресми қолжетімді елдер тізімін тексеріңіз (Anthropic сайтындағы supported countries беті). Ережені айналып өту тәсілдерін қолданбаңыз.
