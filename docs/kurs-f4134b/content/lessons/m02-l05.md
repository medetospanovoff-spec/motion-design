# Claude Code үшін техникалық тапсырма дайындау

## 🎯 Сабақ мақсаты

Сценарийді Claude Code түсінетін толық **техникалық тапсырмаға (ТЗ)** айналдыру. Сабақтың соңында сізде курстың ең маңызды құжаты — **Негізгі промпт** болады.

## 📖 Түсіндірме

Сценарий — «не көрсетеміз». Техникалық тапсырма — «қалай жасаймыз». Claude Code — бағдарламашы. Ол видеоны жасау үшін тек сценарийді емес, техникалық талаптарды да білуі керек:

- **Формат:** 1080×1920, 30 кадр/сек, MP4.
- **Құралдар:** видеоны кодпен жасау, дайын шаблонсыз.
- **Шрифт:** қазақ әріптерін (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І) қолдайтын шрифт. Әйтпесе әріптердің орнына шаршылар шығуы мүмкін!
- **Дыбыс:** авторлық құқықсыз, кодпен генерацияланған музыка.
- **Тексеру:** Claude өз жұмысын өзі тексеріп, қатені түзетуі.
- **Сақтау:** нәтижені қай файлға салу (`output/video.mp4`) және GitHub-қа жіберу.

> 💡 **Неге бұл маңызды?** Claude Code бұлттағы бос компьютерде жұмыс істейді. Ол сіздің телефоныңызды көрмейді және сізге сұрақ қоюы мүмкін. Тапсырма неғұрлым толық болса, ол соғұрлым аз тоқтап, өз бетінше аяқтайды.

### Негізгі промпт құрылымы

1. **Рөл** — «Сен моушн-дизайнер және бағдарламашысың».
2. **Видео туралы** — тақырып, көрермен, ұзақтық, стиль, дауыс.
3. **Сценарий** — 4-сабақтағы кесте.
4. **Техникалық талаптар** — формат, шрифт, музыка, қауіпсіз аймақтар.
5. **Жұмыс реті** — тексеру, сақтау, GitHub-қа жіберу.
6. **Есеп** — соңында не айтып беру керек.

## 🪜 Қадамдар

1. Төмендегі **Негізгі промптты** «Copy» батырмасымен көшіріңіз.
2. «Заметки»-де жаңа жазба ашып, «НЕГІЗГІ ПРОМПТ» деп атаңыз, мәтінді қойыңыз.
3. `[ТІКБҰРЫШТЫ ЖАҚШАДАҒЫ]` әр жерді өз мәліметіңізбен ауыстырыңыз. Жақшаларды өшіріңіз.
4. «СЦЕНАРИЙ» бөліміне 4-сабақтағы кестені қойыңыз.
5. Немесе оңай жол: екінші промптты («Негізгі промптты толтыру») ChatGPT-ге жіберіп, ол бәрін өзі толтырсын.
6. Дайын мәтінді тағы бір рет оқыңыз: жақшалар қалмады ма? Тақырып пен сценарий дұрыс па?

> 📱 **Телефонда ұзын мәтінді өңдеу:** «Заметки»-де сөзді екі рет басып белгілеңіз, белгілеу шекараларын саусақпен сүйреңіз. iPhone-да жүгіргіні (курсор) жылжыту үшін бос орын пернесін (пробел) ұзақ басып, саусақты жылжытыңыз. Android-та көп пернетақтада да осы тәсіл жұмыс істейді.

## ✍️ Практикалық тапсырма

Негізгі промптты толық толтырыңыз. Бұл — **2-модульдің негізгі практикалық тапсырмасы**. Оны 4-модульде Claude Code-қа жібересіз.

## 💬 Дайын промпт

```prompt
# Негізгі промпт: Reels видеосын нөлден жасау (Claude Code үшін)
Сен — тәжірибелі моушн-дизайнер және бағдарламашысың. Осы репозиторийде маған вертикал видео жаса. Мен бағдарламалауды білмеймін және тек телефонды қолданамын, сондықтан барлық жұмысты өз бетіңше толық аяқта. Маңызды шешімдерді өзің қабылда, тек шынымен қажет болғанда ғана сұрақ қой.

ВИДЕО ТУРАЛЫ
- Тақырып: [ТАҚЫРЫП]
- Көрермен: [КІМГЕ АРНАЛҒАН]
- Тіл: қазақ тілі. Экрандағы барлық мәтін қазақша; Ә Ғ Қ Ң Ө Ұ Ү Һ І әріптері дұрыс көрінуі міндетті.
- Ұзақтығы: [15–30] секунд
- Стиль: [МЫСАЛЫ: қара фон #0E1222, қызғылт сары акцент #FF5A1F, ірі жуан әріптер, динамикалық, премиум]
- Дауыс: [ДАУЫССЫЗ — тек музыка және экрандағы мәтін] (немесе: репозиторийдегі voice.m4a файлындағы менің дауысымды қолдан)

СЦЕНАРИЙ
[ОСЫ ЖЕРГЕ СЦЕНАРИЙ КЕСТЕСІН ҚОЙЫҢЫЗ: № | уақыт | экрандағы мәтін | не көрінеді / анимация]

ТЕХНИКАЛЫҚ ТАЛАПТАР
1. Нәтиже: MP4, 1080×1920 (9:16), 30 кадр/сек, H.264 видео + AAC дыбыс, yuv420p, файл көлемі 50 MB-тан аз.
2. Видеоны тек кодпен жаса (мысалы Python + Pillow/numpy немесе HTML/Canvas). Дайын видео шаблондарды, басқа адамдардың видеоларын, стоктық видеоларды және авторлық құқықпен қорғалған музыканы қолданба.
3. Алдымен ортада не орнатылғанын тексер (python3, node, ffmpeg, браузер). ffmpeg жоқ болса, pip арқылы imageio-ffmpeg пакетін орнатып, соның ffmpeg бинарын қолдан. Желі шектеулі болуы мүмкін: қолжетімсіз сайтқа тәуелді болма, балама жол тап.
4. Қазақ әріптерін қолдайтын ашық лицензиялы шрифт қолдан (мысалы, google/fonts репозиторийінен; жүктеу мүмкін болмаса — жүйедегі DejaVu Sans). Шрифт файлын репозиторийге сақта.
5. Музыка мен дыбыс эффектілерін кодпен өзің генерацияла (ырғақты фон музыкасы, сахна ауысқанда whoosh/pop дыбыстары). Дауыс болса, музыка оны баспасын.
6. Кинетикалық типография: мәтін анимациямен шықсын (ұшып кіру, масштаб, сілкініс), сахналар 2–4 секунд сайын ауыссын, жеңіл zoom және өтпелер болсын. Статикалық слайд-шоу болмасын.
7. Қауіпсіз аймақ: маңызды мәтін экранның жоғарғы 12% және төменгі 20% бөлігіне, оң жақ шетке (соңғы 12%) түспесін — оларды TikTok/Instagram батырмалары жабады. Мәтін экраннан шығып кетпесін.
8. Алғашқы 2 секунд көз тартатын болсын (ілгек). Соңғы кадр таза және CTA анық оқылсын.

ЖҰМЫС РЕТІ
1. Жоспарыңды 5–7 пунктпен қысқаша жаз да, бірден орындауға кіріс.
2. Видеоны бір командамен қайта жасайтын скрипт жаса (мысалы, generate.py) және мәтіндерді бөлек конфиг файлға шығар (мысалы, script.json), кейін оңай өзгертуге болатындай.
3. Видеоны толық рендерле. Сапасын өзің тексер: әр сахнадан кадр шығарып қара, мәтіннің кесілмегенін және қазақ әріптерінің дұрыс шыққанын тексер, ұзақтығын, өлшемін, дыбыстың барын тексер. Әлсіз жерді түзетіп, қайта рендерле.
4. Дайын видеоны output/video.mp4 деп сақта.
5. README.md файлына жоба не істейтінін және видеоны қалай қайта жасауға болатынын қазақ тілінде қысқаша жаз.
6. Барлық файлды (видеоны қоса) commit жасап, GitHub-қа push жаса.

СОҢЫНДА маған қазақ тілінде қысқа есеп бер: видео қай branch-те және қай файлда тұр, ұзақтығы мен көлемі қанша, не жасағаныңды 5 пунктпен түсіндір және видеоны жақсарту үшін 3 идея ұсын.
```

«Заметки»-де толық толтырылған **Негізгі промпт** сақталған: онда тақырып, стиль, сценарий кестесі және техникалық талаптар бар. **2-модуль аяқталды!**

## ⚠️ Жиі қателер және шешімдері

- **Техникалық талаптарды өшіріп тастау.** Шешімі: тек жақшадағы жерлерді өзгертіңіз. Талаптар Claude-тың қатесіз жұмыс істеуіне көмектеседі.
- **Жақшалар толтырылмай қалды.** Шешімі: жібермес бұрын мәтіннен «[» таңбасын іздеңіз.
- **ChatGPT үлгіні «жақсартып», талаптарды қысқартып жіберді.** Шешімі: «Үлгінің мәтінін сөзбе-сөз сақта, тек жақшаларды толтыр» деп қайта сұраңыз.
- **Тым ұзын видео (60+ секунд).** Шешімі: алғашқы видео 15–30 секунд — рендер жылдам, қате аз.
