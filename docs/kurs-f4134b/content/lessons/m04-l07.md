# Қателерді түзету

## 🎯 Сабақ мақсаты

Ең жиі кездесетін қателерді тануды және оларды Claude Code көмегімен түзетуді үйрену.

## 📖 Түсіндірме

Қате — қалыпты жағдай. Тіпті кәсіби бағдарламашылардың коды бірінші реттен жұмыс істемейді. Маңызды дағды — **қатені нақты сипаттау**. Claude-қа үш нәрсені айтыңыз:

1. **Не күттіңіз?** («Мәтін толық көрінуі керек еді»)
2. **Не болды?** («3-сахнада сөздің соңы экраннан шығып кетті»)
3. **Қай жерде?** («3-сахна, 7–9 секунд»)

### Жиі қателер кестесі

| Белгі | Мүмкін себебі | Не жазу керек |
|---|---|---|
| Әріптердің орнында шаршылар (□) | Шрифтте қазақ әріптері жоқ | «Қазақ әріптерін қолдайтын шрифт қолдан» |
| Мәтін экраннан шығып кетеді | Мәтін тым ұзын немесе үлкен | «Мәтінді экран еніне сыйдыр, шеттен 80px қалдыр» |
| Дыбыс жоқ | Аудио қосылмаған | «Видеода AAC дыбыс жолы барын тексер» |
| iPhone-да видео ашылмайды / қара | Кодек немесе түс форматы | «H.264, yuv420p, AAC етіп қайта кодта» |
| Видео тым үлкен (100 MB+) | Сапасы тым жоғары | «Видеоны 30 MB-тан аз ет» |
| Claude «network/403/blocked» деп жазады | Ортаның интернет шектеуі | «Бұл сайтсыз балама жол тап» |
| `output/video.mp4` жоқ | Push жасалмаған немесе басқа branch | «Commit жасап, push жаса, branch атауын айт» |
| Сессия тоқтап қалды | Лимит немесе ұзақ күту | Кейін қайта кіріп, «жалғастыр» деп жазу |

### Интернет шектеуі туралы

Default ортасы **Trusted** деңгейде: тек пакет репозиторийлері, GitHub және сенімді домендер ашық. Claude бір сайттан (мысалы, шрифт сайтынан) жүктей алмаса:

1. Алдымен Claude-тан **балама жол** сұраңыз (басқа көз, жүйелік шрифт, т.б.) — көп жағдайда осы жеткілікті.
2. Шынымен қажет болса — ортаның баптауларын өзгертуге болады: сессияның жоғарғы жағындағы орта мәзірі → **Edit** → **Network access** (мысалы, керекті доменді рұқсат етілгендер тізіміне қосу). Бұл жаңа сессияларға қолданылады. Қауіпсіздік үшін **Full** (барлық сайттар) деңгейін тек қажет болса ғана таңдаңыз.

> ⚠️ Құпия кілттерді (API keys, құпиясөздер) ортаның айнымалыларына немесе репоға салмаңыз. Құжаттама ескертеді: ортаны қолданатын кез келген адам олардың мәндерін оқи алады.

## 🪜 Қадамдар

1. Видеоны қарап, мәселені тауып, уақытын жазыңыз (мысалы, «0:07»).
2. Мүмкін болса, скриншот жасаңыз.
3. Claude Code сессиясына төмендегі «Қате туралы есеп» промптын жіберіңіз. Скриншотты хабарламаға тіркеуге болады (қосымшада сурет тіркеу батырмасы болса).
4. Claude түзеткеннен кейін видеоны қайта жүктеп, тексеріңіз.
5. Мәселе қайталанса, Claude-тан себебін түсіндіруді сұраңыз.

## ✍️ Практикалық тапсырма

Видеоңыздан кемінде бір кемшілік табыңыз (тіпті кішкентай болса да) және оны «Қате туралы есеп» промптымен түзетіңіз.

## 💬 Дайын промпт

```prompt
# Қате туралы есеп
Видеода қате бар. Түзет, қайта рендерле, өзің тексер және push жаса.
- Не күттім: [МЫСАЛЫ: мәтін экранға толық сыяды]
- Не болды: [МЫСАЛЫ: «ЖЕТКІЛІКТІ» сөзінің соңы экраннан шығып кетті]
- Қай жерде: [МЫСАЛЫ: 3-сахна, шамамен 0:07–0:09]
Түзеткен соң осы сахнадан кадр шығарып, мәселе шешілгенін тексер. Басқа сахналарды өзгертпе. Себебі мен шешімін қазақ тілінде 2 сөйлеммен түсіндір.
```

## ✅ Күтілетін нәтиже

Қатені нақты сипаттап, Claude арқылы түзете аласыз. Сізде түзетілген видео бар. **4-модуль аяқталды!**

## ⚠️ Жиі қателер және шешімдері

- **«Бәрі нашар, қайта жаса» деп жазу.** Шешімі: нақты не ұнамайтынын 3 пунктпен жазыңыз — әйтпесе Claude жақсы жерлерді де өзгертіп жібереді.
- **Бір хабарламада 10 түзету.** Шешімі: 2–3 түзетуден бастаңыз, нәтижені тексеріп, кейін жалғастырыңыз.
- **Қате қайталана береді.** Шешімі: «Бұл қате үшінші рет қайталанды. Себебін түбегейлі тап, басқа тәсілді қолдан» деп жазыңыз.
