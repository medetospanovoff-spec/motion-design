# GitHub-ты смартфоннан басқару

## 🎯 Сабақ мақсаты

Телефоннан GitHub-та бранчтарды ауыстыру, өзгерістер тарихын қарау, видео файлды жүктеп алу және pull request біріктіру.

## 📖 Түсіндірме

Claude Code жұмысын әдетте **жеке branch-те** (мысалы, `claude/...` деп басталатын атаумен) жасайды және оны GitHub-қа жібереді. Сондықтан видеоны табу үшін сол branch-ке ауысуды білу керек. Бұл — 4-модульдің кілті.

**Branch** — жобаның параллель көшірмесі. `main` — негізгі нұсқа. Claude өз branch-інде жұмыс істейді, сіз нәтижені тексересіз. Ұнаса, **pull request** арқылы `main`-ге қосасыз (міндетті емес).

> 📱 GitHub Mobile қосымшасында да репоны, файлдарды, branch-тарды және pull request-терді қарауға болады. Төменде браузер нұсқасын көрсетеміз — ол әмбебап.

## 🪜 Қадамдар

### 1. Branch-ті ауыстыру

1. Репозиторийіңізді ашыңыз.
2. Файлдар тізімінің үстіндегі **`main`** жазылған батырманы (branch таңдау) басыңыз.
3. Тізімнен керекті branch-ті таңдаңыз (мысалы, `claude/...`).
4. Немесе барлық бранчтар бетін ашыңыз: `github.com/USERNAME/REPO/branches`.

### 2. Өзгерістер тарихын қарау

1. Файлдар тізімінің үстіндегі **commits** (сағат белгісі) сілтемесін басыңыз.
2. Әр commit-ті ашып, қандай файл өзгергенін көре аласыз.

### 3. Видео файлды телефонға жүктеу

1. Видео тұрған branch-ке ауысыңыз (1-қадам).
2. `output` папкасын ашып, `video.mp4` файлын басыңыз.
3. GitHub видеоны алдын ала көрсетуі немесе «View raw» / жүктеу белгісін (төмен көрсеткі) көрсетуі мүмкін. Соны басыңыз.
4. Видео браузерде ашылады:
   - **iPhone (Safari):** «Бөлісу» (квадрат пен жебе) → **«Сохранить видео»** (галереяға) немесе **«Сохранить в Файлы»**. Егер Safari файлды жүктеу ретінде алса — мекенжай жолындағы жүктеу белгісінен ашып, бөлісу арқылы сақтаңыз.
   - **Android (Chrome):** ⋮ → **«Скачать» / Download**, немесе видеоны ұзақ басып → «Скачать видео». Файл «Загрузки» папкасына түседі.

> 💡 **Жедел сілтеме:** `github.com/USERNAME/REPO/raw/BRANCH/output/video.mp4` — видеоны тікелей ашады. `BRANCH` орнына branch атауын жазыңыз.

### 4. Pull request арқылы main-ге қосу (міндетті емес)

1. Репоның **Pull requests** қойындысын ашыңыз.
2. Claude немесе сіз ашқан PR-ды басыңыз (Claude Code-та **Create PR** батырмасы PR ашады).
3. **Files changed** қойындысынан өзгерістерді қараңыз.
4. **Merge pull request** → **Confirm merge** басыңыз.
5. Енді видео `main` branch-те де бар.

## ✍️ Практикалық тапсырма

1. Өз репоңызда branch таңдау мәзірін ашып, қандай бранчтар барын қараңыз (әзірге тек `main`).
2. `brief.md` файлының тарихын ашыңыз (файлды ашып → **History**).
3. Жедел сілтемелер тізімін «Заметки»-ге сақтаңыз. **3-модульдің практикасын «Тапсырма» бөлімінде белгілеңіз.**

## ✅ Күтілетін нәтиже

Branch ауыстыруды, тарихты қарауды, файлды жүктеп алуды және PR біріктіруді білесіз. Сізде жұмыс істейтін GitHub репозиторийі бар. **3-модуль аяқталды!**

## ⚠️ Жиі қателер және шешімдері

- **«output папкасы жоқ».** Шешімі: сіз `main`-де тұрсыз — Claude-тың branch-іне ауысыңыз.
- **Видео браузерде ойнамайды.** Шешімі: оны жүктеп алып, галереядан ашыңыз. Кейбір браузерлер үлкен видеоны алдын ала көрсетпейді.
- **Private репоның raw сілтемесі басқа құрылғыда ашылмайды.** Шешімі: бұл қалыпты — private файлды тек кірген аккаунт көреді. Видеоны бөлісу үшін телефонға жүктеп, сосын жіберіңіз.
- **Merge батырмасы сұр.** Шешімі: PR-да қайшылық (conflict) бар. Claude Code-қа «PR-дағы conflict-ті шеш» деп жазыңыз.

```quiz
? Claude Code нәтижесі әдетте қайда пайда болады?
- Тек main branch-те
+ Жеке branch-те (мысалы claude/... атауымен)
- Электрондық поштада
> Claude өз branch-інде жұмыс істеп, оны GitHub-қа жібереді.

? Видеоны телефонға қалай аламыз?
+ Branch-ке ауысып, output/video.mp4 ашып, жүктеп алу
- Claude-тан поштаға жіберуін сұрау
- Скриншот жасау
> Файлды GitHub-тан ашып, браузердің жүктеу/бөлісу функциясымен сақтаймыз.

? Pull request-ті біріктіру батырмасы қалай аталады?
- Delete branch
+ Merge pull request
- Close issue
> Merge pull request → Confirm merge: өзгерістер main-ге қосылады.
```
