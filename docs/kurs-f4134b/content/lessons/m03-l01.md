# GitHub дегеніміз не?

## 🎯 Сабақ мақсаты

GitHub-тың не екенін және ол біздің видео жобамызға не үшін керек екенін түсіну.

## 📖 Түсіндірме

**GitHub** — жобаларды интернетте сақтайтын сайт. Оны **бұлттағы ақылды папка** деп елестетіңіз (Google Drive сияқты), бірақ бағдарламашыларға арналған.

Біз GitHub-ты 3 нәрсе үшін қолданамыз:

1. **Сақтау.** Видео жобаңыздың барлық файлы (код, шрифт, музыка, дайын видео) бір жерде тұрады.
2. **Claude Code-пен байланыс.** Claude Code жұмысты GitHub-тағы жобаңыздан бастайды және нәтижені соған қайта сақтайды. GitHub — сіз бен Claude арасындағы «ортақ үстел».
3. **Тарих.** GitHub әр өзгерісті есте сақтайды. Бір нәрсе бұзылса, ескі нұсқаға қайта алуға болады.

### Бірнеше жаңа сөз

| Сөз | Қарапайым мағынасы |
|---|---|
| **Repository (репозиторий, «репо»)** | Жоба папкасы |
| **Commit (коммит)** | Өзгерісті сақтау (+ қысқа сипаттама) |
| **Branch (бранч, тармақ)** | Жобаның жеке нұсқасы. Негізгісі — `main` |
| **Push** | Өзгерістерді GitHub-қа жіберу (оны Claude Code жасайды) |
| **Pull request (PR)** | «Менің өзгерістерімді негізгі нұсқаға қосыңызшы» деген ұсыныс |

> 💡 Бұл сөздерді жаттаудың қажеті жоқ. Келесі сабақтарда әрқайсысын іс жүзінде көресіз.

> 📱 **Телефонда GitHub:** GitHub-ты **браузер** арқылы (`github.com`) пайдаланамыз — тіркелу, репозиторий құру, файл жүктеу сол жерде жасалады. Ресми **GitHub Mobile** қосымшасы да бар: ол файлдарды қарауға, хабарламаларға және pull request-терге ыңғайлы, бірақ курстағы барлық қадамдарды браузерде көрсетеміз.

### Git пен GitHub — бір нәрсе ме?

Жоқ. **Git** — компьютерде нұсқаларды басқаратын бағдарлама (терминал командалары). **GitHub** — сайт. Сізге Git командаларын үйренудің қажеті жоқ: GitHub сайты мен Claude Code бұл жұмысты сіз үшін атқарады.

## 🪜 Қадамдар

1. Браузерде `github.com` ашыңыз (әзірге тіркелмейміз).
2. Іздеу арқылы немесе осы сілтеме бойынша кез келген ашық жобаны қараңыз, мысалы `github.com/google/fonts`.
3. Назар аударыңыз: беттің жоғарғы жағында файлдар мен папкалар тізімі, төменде **README** — жобаның сипаттамасы.
4. Бір папкаға кіріп, бір файлды ашып көріңіз.

## ✍️ Практикалық тапсырма

Өз сөзіңізбен «Заметки»-ге жазыңыз: репозиторий, commit және branch дегеніміз не (әрқайсысына 1 сөйлем).

## ✅ Күтілетін нәтиже

GitHub-тың рөлін түсінесіз: жобаны сақтайтын және Claude Code-пен ортақ жұмыс орны.

## ⚠️ Жиі қателер және шешімдері

- **«GitHub — тек бағдарламашыларға» деп қорқу.** Шешімі: бізге оның 5–6 функциясы ғана керек. Бәрін қадамдап көрсетеміз.
- **Git командаларын үйренуге тырысу.** Шешімі: бұл курста қажет емес.
