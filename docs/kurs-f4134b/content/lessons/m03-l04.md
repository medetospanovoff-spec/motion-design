# Репозиторий құру

## 🎯 Сабақ мақсаты

Телефон браузерінен README файлы бар жаңа репозиторий құру.

## 📖 Түсіндірме

Claude Code ресми құжаттамасына сәйкес, жаңа жоба үшін GitHub-та **README файлы бар репозиторий** алдын ала құрылуы керек. Сондықтан репоны **«Add README»** параметрін қосып құрамыз — бұл өте маңызды.

> ⚠️ GitHub беттерінің мобильді нұсқасы кейде батырмаларды жасырады немесе басқа жерге қояды. Егер нұсқаудағы батырма көрінбесе, төмендегі **«Жедел сілтемелер»** тәсілін немесе браузердің **«Толық нұсқа / Desktop site»** режимін қолданыңыз.

### Жедел сілтемелер (ең сенімді тәсіл)

GitHub-тың кейбір беттерін тікелей сілтемемен ашуға болады:

| Әрекет | Сілтеме |
|---|---|
| Жаңа репозиторий | `github.com/new` |
| Репода жаңа файл құру | `github.com/USERNAME/REPO/new/main` |
| Репоға файл жүктеу | `github.com/USERNAME/REPO/upload/main` |
| Репо баптаулары | `github.com/USERNAME/REPO/settings` |

`USERNAME` мен `REPO` орнына өз атауларыңызды жазасыз.

### «Desktop site» режимін қосу

- **iPhone, Safari:** мекенжай жолындағы **«aA»** белгісі (немесе мәзір) → **«Запросить настольный веб-сайт» / «Request Desktop Website»**.
- **Android, Chrome:** жоғарғы оң жақтағы **⋮** → **«Версия для ПК» / «Desktop site»** белгісін қойыңыз.

## 🪜 Қадамдар

1. GitHub-қа кірген күйде браузерде `github.com/new` ашыңыз.
2. **Owner** — сіздің username (өзгертпеңіз).
3. **Repository name** — `my-first-reels` (немесе өз атауыңыз).
4. **Description** (міндетті емес) — «Менің алғашқы AI видеом».
5. **Visibility** — **Private** таңдаңыз.
6. **Add README** (немесе «Add a README file») — **міндетті түрде қосыңыз** (белгі қойыңыз / ауыстырғышты қосыңыз).
7. «.gitignore» және «license» параметрлерін өзгертпеңіз (None).
8. Ең төменде **Create repository** басыңыз.
9. Жаңа репозиторий беті ашылады. Сілтемесі: `github.com/USERNAME/my-first-reels`. Оны «Заметки»-ге сақтаңыз.

> ✅ **Тексеру:** репозиторий бетінде `README.md` файлы көрінуі керек. Көрінбесе — README қосылмаған. Онда келесі сабақтағы тәсілмен `README.md` файлын қолмен құрыңыз.

## ✍️ Практикалық тапсырма

`my-first-reels` репозиторийін (Private, README-мен) құрыңыз. Сілтемесін сақтаңыз. Бұл — 3-модуль практикасының бірінші бөлігі.

## ✅ Күтілетін нәтиже

`github.com/USERNAME/my-first-reels` ашылады, ішінде `README.md` бар.

## ⚠️ Жиі қателер және шешімдері

- **«Repository name already exists».** Шешімі: сізде осындай атаулы репо бар — басқа атау беріңіз немесе барын қолданыңыз.
- **Create repository батырмасы белсенді емес.** Шешімі: репо атауын енгізгеніңізді тексеріңіз; беттің төменіне дейін айналдырыңыз.
- **README қосуды ұмыттым.** Шешімі: келесі сабақта көрсетілгендей `README.md` файлын құрыңыз.
- **Батырмалар көрінбейді.** Шешімі: Desktop site режимін қосыңыз немесе жедел сілтемелерді қолданыңыз.
