# Аккаунт құру

## 🎯 Сабақ мақсаты

Телефон браузері арқылы тегін GitHub аккаунтын ашу және оны қорғау.

## 📖 Түсіндірме

GitHub аккаунты тегін. Сізге электрондық пошта, құпиясөз және **username** (пайдаланушы аты) керек. Username сіздің жобаларыңыздың сілтемесінде көрінеді: `github.com/USERNAME`.

**Username таңдау кеңестері:**

- Тек латын әріптері, сандар және сызықша (`-`).
- Қысқа, оңай есте қалатын: `aigerim-creates`, `nurlan-ai`.
- Кейін өзгертуге болады, бірақ сілтемелер өзгереді — бірден дұрысын таңдаңыз.

> ⚠️ **Интерфейс туралы:** GitHub тіркелу бетін жиі жаңартады. Төмендегі қадамдардың реті немесе батырмалардың аты сәл өзгеше болуы мүмкін. Беттегі нұсқауларды мұқият оқыңыз.

## 🪜 Қадамдар

1. Браузерде `github.com/signup` ашыңыз.
2. **Email** енгізіңіз → **Continue**.
3. **Password** ойлап табыңыз (кемінде 15 таңба, немесе кемінде 8 таңба + сан + кіші әріп) → **Continue**. Құпиясөзді телефонның құпиясөз менеджеріне сақтаңыз.
4. **Username** енгізіңіз. Жасыл белгі шықса — бос. Қызыл болса, басқасын таңдаңыз → **Continue**.
5. Жаңалықтар туралы хат алу сұрағына қалауыңызша жауап беріңіз.
6. **Verify** — «сіз робот емессіз» тексерісі (суреттер немесе жұмбақ). Нұсқауды орындаңыз.
7. **Create account** басыңыз.
8. Поштаңызға GitHub **8 таңбалы код** жібереді. Оны енгізіңіз.
9. GitHub сізден бірнеше сұрақ қоюы мүмкін (командада қанша адам т.б.) — оларды өткізіп жіберуге (**Skip**) немесе қарапайым жауап беруге болады.
10. Тегін жоспарды (**Free**) таңдаңыз, егер сұраса.

### Аккаунтты қорғау: екі факторлы аутентификация (2FA)

GitHub қауіпсіздік үшін **2FA** (екі қадамды кіру) қосуды сұрауы мүмкін. Бұл — құпиясөзден бөлек, телефондағы кодты енгізу.

1. Профиль суретіңізді басыңыз → **Settings** → **Password and authentication**.
2. **Enable two-factor authentication** басыңыз.
3. Телефонда тексеру қосымшасын қолданыңыз (мысалы, ресми GitHub Mobile, Google Authenticator немесе Microsoft Authenticator).
4. **Recovery codes** (қалпына келтіру кодтары) шығады — оларды **міндетті түрде** сақтаңыз (скриншот + қауіпсіз жер). Телефон жоғалса, тек солар арқылы кіресіз.

> 📱 **Мобильді кеңес:** QR кодты сол телефонмен сканерлей алмайсыз. Оның орнына «setup key» / «enter this text code» сілтемесін басып, мәтіндік кілтті көшіріп, тексеру қосымшасына қойыңыз.

## ✍️ Практикалық тапсырма

GitHub аккаунтын ашыңыз. Профиль бетіңіздің сілтемесін (`github.com/USERNAME`) «Заметки»-ге сақтаңыз.

## ✅ Күтілетін нәтиже

Сізде расталған GitHub аккаунты бар және `github.com/USERNAME` сілтемесі ашылады.

## ⚠️ Жиі қателер және шешімдері

- **Код поштаға келмейді.** Шешімі: «Спам»/«Промоакции» қалтасын тексеріңіз, бірнеше минут күтіп, **Resend** басыңыз.
- **Робот тексерісі өтпей жатыр.** Шешімі: басқа браузерді (Safari ↔ Chrome) байқап көріңіз, VPN болса өшіріңіз.
- **Recovery codes сақталмады.** Шешімі: Settings → Password and authentication бөлімінен оларды қайта көрсетуге/жаңартуға болады — дереу сақтаңыз.
- **Username бос емес.** Шешімі: соңына сан немесе сөз қосыңыз: `aigerim-ai`, `aigerim2026`.
