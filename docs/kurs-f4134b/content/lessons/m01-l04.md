# Видео жасау процесінің жалпы схемасы

## 🎯 Сабақ мақсаты

Идеядан жарияланған видеоға дейінгі бүкіл жолды бір схемада көру және әр қадамда қай құрал қолданылатынын білу.

## 📖 Түсіндірме

Бүкіл процесс 6 қадамнан тұрады. Әр модуль осы қадамдардың біріне арналған:

| № | Қадам | Құрал | Модуль | Нәтиже |
|---|---|---|---|---|
| 1 | **Идея** | ChatGPT | 02, 06 | Видео не туралы |
| 2 | **Сценарий** | ChatGPT | 02 | Сахналар мен мәтін |
| 3 | **Промпт (техникалық тапсырма)** | ChatGPT + үлгі | 02 | Claude Code-қа нұсқау |
| 4 | **Жоба орны** | GitHub (браузер) | 03 | Репозиторий |
| 5 | **Видео жасау** | Claude Code (Claude қосымшасы) | 04, 05 | `output/video.mp4` |
| 6 | **Жариялау** | TikTok / Instagram / YouTube | 06 | Жарияланған видео |

### Ақпарат қалай жүреді

```
Сіздің идеяңыз
   ↓  (ChatGPT)
Сценарий + кәсіби промпт
   ↓  (көшіріп, Claude Code-қа қоясыз)
Claude Code бұлтта код жазып, видео жасайды
   ↓  (нәтижені GitHub-қа сақтайды)
GitHub репозиторийіндегі video.mp4
   ↓  (телефонға жүктеп аласыз)
TikTok / Reels / Shorts
```

> 💡 **Есте сақтаңыз:** ChatGPT — «сценарист», GitHub — «папка», Claude Code — «монтаждаушы-аниматор», сіз — «режиссер». Режиссер не қалайтынын нақты айтады — бұл сіздің ең маңызды рөліңіз.

### Бір видеоға қанша уақыт кетеді?

- Алғашқы рет: курс бойынша **бірнеше күн** (оқу + тіркелу + үйрену).
- Үйреніп алғаннан кейін: идея мен сценарийге **15–20 минут**, Claude Code жұмысына **10–40 минут** (бұл кезде телефонды қоя тұруға болады), тексеру мен түзетуге **10–20 минут**.

> ⚠️ Claude Code жұмыс уақыты видеоның күрделілігіне және сервистің жүктемесіне байланысты өзгереді. Жоғарыдағы сандар — бағдар ғана.

## 🪜 Қадамдар

1. Жоғарыдағы кестені қайта оқыңыз.
2. Телефонда скриншот жасаңыз немесе кестені «Заметки»-ге көшіріңіз.
3. Әр қадамның жанына өз видеоңыз туралы бір сөз жазыңыз. Мысалы: «Идея — нан пісіру туралы».

## ✍️ Практикалық тапсырма

«Заметки»-де «Менің AI-видео жоспарым» жазбасын ашыңыз. 5 жолды толтырыңыз:

1. Видео тақырыбы: ...
2. Кімге арналған: ...
3. Видеодан кейін көрермен не істеуі керек (жазылу, пікір жазу, сатып алу): ...
4. Ұзақтығы (15 / 20 / 30 секунд): ...
5. Стиль (мысалы: қара фон + қызғылт сары мәтін; ақ минимализм; неон): ...

Бұл — 1-модульдің негізгі практикалық тапсырмасы. Оны «Тапсырма» бөлімінде белгілеуді ұмытпаңыз.

## 💬 Дайын промпт

```prompt
# Видео идеясын нақтылау
Мен бірінші вертикал видеомды жасағым келеді (TikTok / Reels). Менің тақырыбым: [ТАҚЫРЫП].
Маған қазақ тілінде көмектес:
1) Осы тақырыпқа 15–30 секундтық видеоның 5 түрлі идеясын ұсын.
2) Әр идеяға: кімге арналған, басты ой (1 сөйлем), алғашқы 3 секундтағы «ілгек» (hook) фразасы.
3) Жаңадан бастаушыға ең оңай жасалатын 1 идеяны белгілеп, неге екенін түсіндір.
```

## ✅ Күтілетін нәтиже

Сіз бүкіл процесті түсінесіз және өз видеоңыздың алғашқы жоспары бар. **1-модуль аяқталды!**

## ⚠️ Жиі қателер және шешімдері

- **Бірден күрделі видео жоспарлау** (2 минуттық, 20 сахналы). Шешімі: алғашқысы 15–30 секунд, 4–6 сахна болсын.
- **Тақырыпты таңдай алмау.** Шешімі: өзіңіз жақсы білетін нәрсені таңдаңыз — жұмысыңыз, хоббиіңіз, қалаңыз.
- **Мақсатсыз видео.** Шешімі: соңында көрермен не істеуі керек екенін алдын ала шешіңіз (CTA — call to action, «әрекетке шақыру»).
